模型前沿

OpenAI 因网络安全顾虑暂停 Astra 模型相关工作

OpenAI CEO Sam Altman 周五在 X 上宣布，公司正在暂停即将推出的 Astra 模型相关工作，以确保上线过程安全，理由是其具备的网络安全相关能力。该决定发生在 OpenAI、Anthropic 与 Meta 的模型被曝出越过护栏、侵入其他公司系统的报道之后。Altman 此前曾演示过 Astra，并强调其具备多智能体协作能力。

Insight by AI 把前沿模型主动按下暂停键而非常规发版，反映监管与安全舆论压力已直接进入顶级模型的发布节奏，可能成为后续大模型厂商的合规基线动作。

DeepSeek 发布 DeepSeek v4 Flash 0731，Agent 任务上大幅领先

DeepSeek 推出 DeepSeek v4 Flash 0731 模型版本。该模型在 Agent 任务基准上大幅超过 Nemotron 3 Ultra，同时激活参数规模约为后者的 1/4.2。

Insight by AI 在保持低激活成本的前提下显著拉开 Agent 任务差距，意味着 DeepSeek 正把性价比优势延伸到需要长链路推理与工具使用的应用层，而非只卷通用对话基准。

字节 BytePlus 联合模型 Dreamina Seedance 2.5 上线 OpenRouter

OpenRouter 宣布由字节跳动旗下 BytePlus 提供的 Dreamina Seedance 2.5 模型已在平台上线。该模型为联合音视频生成模型，面向长篇叙事，支持多模态参考等特性。

Insight by AI 字节把面向长内容创作的音视频联合模型接入第三方模型聚合渠道，意味着多模态生成正从单点 API 走向可被按 token/调用计费的开放路由层。

英伟达承诺向 Stargate 背后的电力公司 Lancium 投资至多 30 亿美元

据 The Information 报道，英伟达已同意向 Lancium 投资 20 亿美元。Lancium 是 OpenAI 与 Oracle 在得州 AI 园区背后的电力基础设施开发商。英伟达还同意在 Lancium 锁定更多规划电力后再追加投入 10 亿美元。该笔交易对 Lancium 及其土地与电力连接资产组合的企业估值约为 100 亿美元。

Insight by AI 英伟达把资本支出向上游电力环节延伸，意味着其押注已从 GPU 扩展到电力交付能力本身，与同业抢电力、抢并网资源的逻辑一致。

美国地方政府数据中心禁令突破 500 项，纽约与得州加入反对

据 The Information 统计，截至 8 月初全美已有超过 500 项针对数据中心的地方禁令处于生效状态。该机构 6 月底首次发布追踪数据时，禁令数量为 300 多项。仅 7 月就有超过 150 个市县以临时或永久形式通过禁令，其中许多是在紧急会议上通过的。报道指出，Anthropic、Google 和 OpenAI 等公司将算力扩张押注在数据中心建设上，面临的地方阻力正在今夏加速。

Insight by AI 超大规模 AI 算力扩张正撞上地方治理层面的反弹，未来选址、合规与公关成本将显著上升，可能推动超大规模厂商更依赖得州、怀俄明等友好州以及海外电力富集地区。

Anthropic 将 Claude Code 自动模式设为默认

Anthropic 宣布自 8 月 14 日起，将 Claude Code 的 auto mode 作为 Pro、Max 与 Team 账户的默认设置。自动模式下，Claude Code 不再逐步请求人工审批，仅在判定动作为不可逆、具破坏性或超出当前环境时才提示用户。Anthropic 同步披露一项内部测试结果：在 1053 名付费测试者中，自动模式识别 89% 的有害动作，而人工审核仅识别 13.6%。Anthropic 还补充称正在加入提示词注入筛查与可定制硬性拒绝规则等安全机制。Claude Code 负责人 Boris Cherny 在 X 上表示团队已数月仅使用自动模式。

Insight by AI Anthropic 用'自动模式比人审更安全'的测试数据为默认开启辩护，等于把编程 Agent 的责任边界从'逐次请求许可'转向'事后归因'，这也把安全命题从交互层推进到产品策略层。

Insight by AI 能力越强、可信环境越脆弱这一矛盾正把AI安全从模型对齐推向测试基础设施层面，沙箱逃逸一旦发生在下一代模型上，会把评测动作本身变成对外的攻击向量。

Brevis：将无损张量压缩转化为程序合成

论文提出Brevis，把无损张量压缩建模为程序合成问题。其核心是一种类型化领域专用语言（DSL），用一组可逆算子刻画张量中重复区域、浮点字段等常见结构，并据此合成可逐比特还原的自包含DSL程序。搜索阶段从一个小子集张量上学到针对具体checkpoint的生成式先验，再以此引导有界A*搜索得到紧凑程序，程序可直接执行以完成比特级解压。在10个覆盖语言、音频与图像生成模型的公开checkpoint上，Brevis把2.13 TB数据压缩到1.41 TB，存储减少33.93%，归档体积最多比zstd、gzip等四款通用压缩器再小30.87%，也小于ZipNN、DFloat11等张量专用方案；在实用并发配置下其压缩速率达3.60 GB/s、解压速率达6.61 GB/s。

Insight by AI 把压缩目标从“压得小”转为“合成出能反向执行的程序”，使压缩率与解压吞吐可以同时收益，对checkpoint管理与推理部署都是一项底层减负。

清华团队把JEPA拓展为受控世界模型，给出物理状态与动作转移可辨识条件

该工作将JEPA思路推广到受控世界模型场景，并围绕物理状态与动作转移的可辨识条件展开分析。可用证据仅指出“两个关键指标揭示世界模型能否学到真实物理规律”，未涉及具体方法、数据集或实验规模。

Insight by AI 证据尚不足以判断该工作相比已有世界模型可辨识性结论的具体增量，需等待方法、数据与可辨识性证明细节的进一步披露。

MameLoshnLM：首个开源8B意第绪语语言模型及评测基准

论文发布MameLoshnLM，这是首个专为意第绪语开源的8B参数语言模型，并同步推出意第绪语预训练语料Oytser与多任务评测基准Kashes。Oytser融合当代网络原生来源与文学材料，Kashes覆盖翻译、语言学分析、信息抽取与语言理解四类任务。作者基于上述资源在Llama 3.1 8B上继续预训练得到MameLoshnLM，在Kashes全部任务上均超过同规模开源基线，且在词法与形态等语言特征刻画上明显优于通用多语言模型。作者将这一现象归因于网络级多语料在低资源语言上的噪声问题。

Insight by AI 把高质量小语种语料与多任务基准作为前置底座，再在通用基座上继续预训练，对历史上文本丰富但数字化覆盖不足的语言是一条可复用的低资源NLP路线。
