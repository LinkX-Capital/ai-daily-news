## 一句话判断

AI4S 正从「单点预测模型」跨入「科研生产系统」阶段：竞争主战场已不是模型参数与榜单，而是能否把**通用推理模型 + 科学专用模型 + 多智能体 + 专业工具 + 科学数据 + 高性能算力 + 自动化实验**连接成可审计、可复现、可持续学习的闭环。最强信号是头部模型公司通过美国 **Genesis Mission** 绑定国家科研算力与数据；同时生命科学/材料/天气/电网的垂直模型、科研知识基础设施与中国全栈平台正同步成型。

## 三、近期核心进展（按六维框架组织）

### 1. 国家实验室级绑定（最强信号）——Genesis Mission 升格为「国家科技动员操作系统」
- **制度起点**：Genesis Mission 由美国总统 2025‑11‑24 行政令启动、DOE 牵头，目标十年内将美国科学发现速度翻倍，把国家实验室超算、数据集与实验设施整合为闭环 AI 平台。
- **组织五层**：数据团队 / 基础设施团队 / 模型团队 / 国家挑战团队 / 公私合作团队；伙伴名单已超 60 家（OpenAI、Google、Anthropic、NVIDIA、Microsoft、AWS、xAI、IBM、Siemens、Synopsys、FutureHouse、LILA 等）。
- **头部公司切入（管线 + 一手源）**：OpenAI 向约 2000 名研究者提供 $400 万 Codex + $300 万 API，在 Los Alamos 的 Venado 超算部署高级推理模型；Google 提供 $4000 万 token+云额度，开放 AlphaEvolve / AlphaFold 3 / AlphaGenome / WeatherNext / AlphaEarth；Anthropic 提供 Claude 访问 + 连接科研仪器的 MCP 服务器。
- **首个实物示范 Aires Tide**（06‑24，NNSA）：AI+HPC+增材制造飞行试验体，用 Venado 与 El Capitan 两台超算设计，5 个月完成设计—建造—测试（传统约 2 年），成本低 15×、快 7×，完成两次飞行试验。**成熟度判断**：计划已从政治倡议进入「平台定义与示范验证」阶段，但全国统一数据底座、跨实验室互操作、稳定拨款与可审计成效指标仍是规模化关键。
- **Quantum Genesis（06‑23，DOE 官网确认）**：Genesis 的核心组成，目标 **2028 年前部署全球首台「科研级容错量子计算机」**。三大支柱：① **DOE Q 竞赛**——2028 年演示低百位逻辑量子比特的容错系统，攻坚化学/材料/等离子物理/高能物理；② **国家量子超算用户设施**——多模态量子系统与传统 HPC、AI、高速网络异构融合，形成统一 HPC‑AI‑量子计算生态；③ **量子应用定向 R&D**。该计划把 AI、超算、量子、实验设施纳入同一长期路线，是 Genesis 从「AI 平台」扩为「国家发现操作系统」的关键拼图。
- 注：伙伴承诺金额（OW $400 万/$300 万、Google $4000 万）属企业侧投入；DOE 另有 FY27 AIQ 办公室预算申请（朋友报告口径 $12 亿，与 $2.93 亿「赛马」资金机会为不同口径，申请 ≠ 国会最终拨款）。

### 2. 模型架构：从单模型转向「模型—智能体—工具」复合系统
- **领域化前沿推理模型**：GPT‑Rosalind 基于 GPT‑5.5 增量训练 + 生命科学数据，接入 50+ 工具；Gemma 4 12B 取消独立视觉/音频编码器（统一多模态），16GB 笔记本可运行——利于科研仪器与本地敏感数据。
- **多智能体科研系统**：Co‑Scientist 由生成/相似/反思/排序/进化/元审查智能体组成，上层监督者自适应规划，「想法锦标赛」扩展探索空间；Claude Science 用通用协调智能体 + 派生专家智能体 + 独立审稿智能体，强调引用与计算复核。
- **带科学归纳偏置的专业基础模型**：MatterSim‑MT 在原子结构表示上设能量/力/应力/多性质任务头；GridSFM 将电网表示为有向图，用块结构离散神经算子直接输出交流潮流；Aurora 1.5 引入随机扰动与集合预报，以分布而非单点表达不确定性。
- **规律**：LLM 正成为「科研操作系统的控制平面」，数值真值仍由科学基础模型、传统求解器、数据库与实验设备提供。壁垒更可能来自编排、评测与闭环，而非单一模型参数量。

### 3. 模型训练：多阶段、可验证、以真实任务为目标
- **多阶段微调成常态**：Aurora 1.5 先扩变量与时序分辨率，再注入受控扰动，最后用 2018–2023 ECMWF 分析数据自回归微调以稳长期滚动。
- **求解器监督 + 物理约束**：GridSFM 同时学传统 AC‑OPF 求解器标签与基尔霍夫定律/热极限约束，既能覆盖可行区也能识别不可行区。
- **多任务训练扩大可复用范围**：MatterSim‑MT 先学能量/力/应力，再对 Bader 电荷、磁矩、Born 有效电荷等微调，从势能面代理扩展为材料表征基础模型；其实验验证版仅需 3% 原始数据达实验精度。
- **训练基础设施异构化**：Google Decoupled DiLoCo 将训练拆成跨数据中心异步「计算岛」，官方实验跨 8 个数据中心带宽由 198Gbps 降至 0.84Gbps，高故障率下有效产出率 88%（传统数据并行 27%），并可混用不同代际 TPU。
- **智能体 RL 基础设施成熟**：反复出现可验证奖励、工具调用轨迹与失败恢复，表明「任务执行轨迹」正成为新训练样本。

### 4. 训练数据：从文本语料扩展到仿真、结构、观测与实验反馈
- 数据结构三层变化：① 单元从文档 token → 图/3D 结构/网格/场/时序/工具轨迹；② 标签从人工文本 → 第一性原理、传统求解器、高质量观测；③ 评测更重「未公开、未污染、真实实验」。
- 例：MatterSim‑MT 用 3500 万+ 第一性原理标注结构（89 元素、最高 5000K/1000GPa）；GridSFM 主动构造 150+ 网架、约 50 万组合以覆盖分布多样性。
- **数据瓶颈不在数量而在治理**：标准不一致、负结果缺失、实验条件不完整、IP 与安全边界。能形成高质量数据谱系并把实验结果自动回流的机构，将拥有比单纯购买算力更持久的优势。

### 5. 模型能力：已能进入闭环，但尚未达到可靠自主科学家
- **三层证据**：① 公开基准（GPT‑Rosalind 在 LABBench2 的 11 项任务有 6 项优于 GPT‑5.4；SciAgentArena 约 200 个交互式科学任务显示，当前智能体在边界清晰的数据分析流程上已能较好支持）；② 未公开专家对照（Dyno 未公开 RNA 任务 best‑of‑10 超 95% 人类专家历史分位）；③ 实验/运行验证（MatterSim 筛 24 万候选后实验测得 TaP 热导率 152 W/m/K；Aires Tide 两次飞行试验；Molecule.one 10080 次反应台架复验）。
- **能力上限的量化标尺**：Microsoft Research 的 **SciAgentArena**（06‑10，论文 + 开源基准，18 个智能体跨 7 大领域 ~200 任务、分步验证 + 交互式评测）刻画了当前 Agent 的「 unevenness」——在结构清晰、评测标准明确的单细胞/组学/EHR 数据流程上可过关，但在**原创洞察、持续自主探索、开放式科研问题**上明显薄弱，并系统归纳了 6 类失败模式（保守收敛/流行偏见、工具与 API 幻觉、运行时脆弱、 validity 检查缺失/谄媚式盲从等）。这与 GeneBench‑Pro（最强系统仅 31.5%）相互印证：**Agent 尚未成为可靠自主科学家**。
- **物理闭环硬证据**：OpenAI × Molecule.one（06‑17）将 GPT‑5.4 接入 Maria 自动化化学平台，在专家把关下优化 Chan–Lam 偶联，10080 次反应后平均产率 16.6%→25.2%（>30% 产率反应占比 15.6%→37.5%），人类台架复验 11/14 底物对提升——这是「模型+自动化实验+人类判断」半闭环协作，而非自主科学家。
- **能力边界**：企业披露的速度/分位多来自特定任务与选择性指标；best‑of‑N 显著抬升推理成本；实验验证通常是少量候选成功案例。现阶段合理定位是「高能力科研协作者 / 半自主科研系统」。

## 四、研判：四条趋势（规律 + 驱动力）

**T1. 竞争单位从「模型」变为「科研生产系统」。**
*规律*：单模型能力快速商品化，真正差异来自是否连通文献、数据、代码、模型、算力、仪器与人类审批形成可持续闭环。*驱动力*：通用推理模型能力提升；MCP/Skills 工具协议成熟；科研流程高度碎片化。

**T2. 通用底座与专业能力「解耦组合」。**
*规律*：主流路线不是每个学科从零训大模型，而是通用推理模型作协调器 + 领域增量训练 + 专业模型 + 数据库/工具。*驱动力*：通用模型进步更快；领域训练昂贵；科学工具与数据高度专业化。

**T3. 训练重心从「更多语料」转向「更强反馈」。**
*规律*：求解器标签、物理约束、仿真、工具轨迹、未公开任务与实验结果成为训练/评测核心。*驱动力*：公开文本边际收益下降；科学任务天然存在可计算/可实验奖励信号；合成场景可覆盖极端条件。

**T4. 价值实现由「软件闭环」走向「物理闭环」。**
*规律*：当 AI 连接高通量实验、机器人、数字孪生与中试产线，才能把「建议」变可验证成果并反哺训练数据。*驱动力*：实验自动化降本；生命科学/材料研发周期长、价值高；制造与安全任务可量化。

> 最重要新规律：**AI4S 的能力上限由模型决定，但落地速度由「数据—工具—实验—组织」决定**。短期领先可来自更强模型，长期壁垒来自可持续积累的闭环资产。

## 五、跟踪仪表盘（指标 + 预警信号）

| 跟踪主题 | 建议指标 | 预警信号 |
|---|---|---|
| 技术 | 长程任务成功率；工具调用正确率；不确定性校准；实验复现率 | 只报静态榜单；不披露总推理成本；无失败案例 |
| 数据 | 可追溯数据比例；负结果占比；闭环回流周期；跨机构可用性 | 数据授权不清；训练/评测混用；实验条件缺失 |
| 产品 | 活跃科研项目数；完成工件数；专家采纳率；节省周期 | 演示多、持续使用少；人工兜底不可见 |
| 产业 | 付费客户与续费；工具/仪器伙伴；试点→生产转化率 | 生态名单大但接口/合同未落地 |
| Genesis | 预算、超算交付、数据标准、挑战里程碑、开放访问规则 | 拨款延迟；平台互操作无公开证据；成果仅限单点示范 |
| 中国 | 国家级挑战清单、AI‑ready 数据资产化率、自主实验室验证场 | 重复训模型、接口碎片化、缺乏统一评测 |

## 六、风险与瓶颈

- **数据壁垒与可复现性**：垂直科学模型质量取决于专有、标注良好的领域数据；激励相容的数据供给仍是空白。
- **奖励黑客 / 对齐**：科学发现场景 RL 易产生 reward‑seeking；诚实取决于是否被监督。
- **人才与治理变量**：AlphaFold 核心 John Jumper 离 Google（06‑21）；Hassabis 呼吁美国主导的全球 AI 监管机构（07‑15）若落地将改变前沿模型发布节奏与合规成本。
- **能源与算力硬约束**：BloombergNEF 预计 2035 年美国数据中心耗电达当前 4 倍；核聚变（Helion 估值 155 亿美元）是长线解法但远未商业化。
- **自主能力安全边界**：前沿模型已被证实可链式利用漏洞越界；科研自主 Agent 需更强沙箱与护栏。

## 七、研判与建议

### 7.1 对科研机构 / 政策制定者
- 优先选择具有明确验证器的领域（材料、电网、天气、计算化学），建立可量化闭环。
- 建设「数据产品」而不只是数据湖：每条数据具备来源、条件、版本、权限、质量与可复现元数据，并保留负结果。
- 以模块化架构避免单一厂商锁定：通用模型/领域模型/数据库/求解器/HPC/仪器经可替换接口连接。
- 把评测嵌入真实任务：未公开、时间截断、专家盲评、实验验证四类评测，披露 best‑of‑N 与总计算成本。

### 7.2 对企业与投资方
- 产品定位从「AI 科研助手」收敛到一个可量化瓶颈（候选筛选 / 仿真加速 / 文献证据图谱 / 实验排程 / 合规报告）。
- 把可复现工件、审计与权限作为核心产品能力，而非上线后合规模块。
- 关注数据与实验反馈的排他性：通用模型能力会快速扩散，独特闭环数据与客户工作流更能形成护城河。
- 谨慎解读「倍数提升」：要求给出基线、任务范围、失败率、人工介入、推理成本与独立验证。

### 7.3 我国：已有点状突破，亟需国家级系统集成
| 维度 | 我国已有基础 | 需要补齐 |
|---|---|---|
| 任务组织 | 重大专项、地方计划与科研机构场景丰富，工程动员能力强 | 缺跨部门统一国家 AI4S 挑战清单、公共里程碑与滚动赛马机制 |
| 平台底座 | 超算、智算、科学设施、模型平台均有布局 | 算力/数据/模型/工具/实验/中试仍多分散建设，接口与权限不统一 |
| 科学数据 | 长期积累大量科学/产业数据，部分领域场景优势明显 | AI‑ready 改造不足，过程/失败/来源/版本/实验条件未系统资产化 |
| 模型与工具 | 学科/行业模型数量增长快，开源生态活跃 | 与真实科研工具链、HPC、仪器稳定连接不足，可复用科学技能少 |
| 实验闭环 | 部分机构/头部企业已有自动化实验及 AI 闭环（KrF 光刻胶） | 自主实验室缺统一标准、共享机制与规模化验证场 |
| 产业生态 | 制造业场景多、转化链条完整、地方资本积极 | 模型公司/科学软件/仪器/数据/实验服务/产业用户尚未形成稳定联盟与采购市场 |
| 评价治理 | 安全治理与科研管理已有制度基础 | 缺针对科研判断、证据链、可复现性、长程任务的统一评测体系 |

**六项优先行动**：① 建立少而精的国家级科学智能挑战清单（18 个月可验证成果）；② 建设分布式「国家科学智能平台」底座（开放/产业可信/涉密分级）；③ 把「科学数据工厂」（含过程、失败、来源、版本）列为核心工程；④ 形成「TaaS + 科研驾驶舱 + 自主实验室」共性能力；⑤ 以采购与验证场做强产业联盟，设驻场「前沿部署研究工程师」；⑥ 建立面向真实科研价值的评价与安全制度（可信准入、最小权限、全链审计）。
