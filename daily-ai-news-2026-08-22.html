DeepSeek 上线实验性多模态视觉理解模型 DeepSeek-V4-Flash-Vision-Exp

DeepSeek 于今日下午正式上线实验性多模态视觉理解模型 DeepSeek-V4-Flash-Vision-Exp，并同步开放相关能力接口。该模型补齐了 DeepSeek 在 Agent 路线上的视觉输入短板，让 Agent 任务能够直接基于图像与视频画面进行决策与交互。

Insight by AI 视觉补齐意味着 DeepSeek 把感知层交给了开源生态、模型层专注 Agent 工作流，这条路线与 OpenAI/Anthropic 的“原生多模态+工具调用”同构，但通过开放权重进一步压低国内多模态 Agent 的部署成本。

vLLM 团队发布 IsoExec：统一 SkyRL 训练与推理执行路径

IsoExec 是面向 RL 工作负载的跨框架统一执行抽象，由执行合约与统一模型两部分组成，旨在消除训练引擎与推理引擎之间的浮点差异。IsoExec 在 SkyRL 的 vLLM 与 Megatron 运行时之间对齐模型定义、并行布局和分块计算逻辑，并在 Qwen3.5-35B-A3B 上将 rollout 与 training 的 logprob 差异压至 1e-6 以下，整体开销约 25%。

Insight by AI RL 系统层的浮点发散是新算法、Harness 改动和硬件优化难以调试的隐性根源，把执行路径抽象成可强制对齐的合约，是把 RL infra 从“近似一致”推向“比特级一致”的工程范式。

HuggingFace 论文提出 EnvHarness：用可编程插件层改造静态训练环境

EnvHarness 通过标准接口将可插拔组件包裹在静态环境之外，在不动底层逻辑的前提下重塑环境行为，并保证重塑后的环境仍使用原有 verifier。配套的 EnvRigger 把目标策略当作黑盒，根据执行轨迹合成针对诊断缺陷的 EnvHarness 组件，并用新一轮 rollout 验证。论文在四个领域、五个 benchmark 上报告了相对原始环境和领域专用生成管线的提升，在留置实例上最高取得 9.0 分改进，rollout 步数减少 9.8%。

Insight by AI 用“包一层而不是重建一个”来做环境进化，把环境生成为可复用、可验证的中间件，绕开了昂贵 verifier 和领域管线的限制，更适合作为 RL 训练的持续共进化信号源。
HuggingFace Daily Papers

机器之心报道 Spark-to-Paper：端到端论文生成系统直接产出初稿

Spark-to-Paper 以 13 个可组合技能的形式运行在现有编程助手内部，无需独立部署智能体平台或外部编排服务。从一句研究想法出发，系统会顺序执行文献检索、实验设计等环节，并直接输出论文初稿。原文还披露该系统对假结论的检出率达到 92%，并支持自动跑实验与画图。

Insight by AI 论文生成从“辅助写作”走向“端到端流水线”，可组合技能 + 内置于编程助手是降低部署门槛的关键，但 92% 的假结论检出率也意味着剩余 8% 仍需人工把关，验证机制将成为后续竞争焦点。

浙大 BEACON：按里程碑分配信用，长程 Agent 成功率近翻倍

该工作入选 ICML 2026，针对长程 Agent 在稀疏奖励下信用分配困难的问题。BEACON 按里程碑分配信用，把长轨迹分解为若干子目标，使策略更新能够定位关键决策点。论文在公开的长程任务基准上验证，将成功率由较低水平提升至接近翻倍的可比对照。

Insight by AI 稀疏奖励下的信用分配一直是 RL 训练长程 Agent 的瓶颈，按里程碑分阶段拆分的思路与子目标课程学习一脉相承；在开源复现成熟后，有望成为长程 Agent 训练栈中的标准插件。
PaperWeekly

ForgeWM：以渐进式因果训练把动作条件视频世界模型压到 1–4 步

动作条件视频世界模型需要低延迟的因果生成，并对游戏原生控制做出可靠响应。ForgeWM 把一个双向动作条件视频生成器转化为少步世界模型，采用四阶段渐进框架：领域适配、教师强制式因果训练、因果一致性蒸馏，以及配合双向教师的 in-policy 分布匹配。学生模型可稳定工作在 1、2、4 步去噪预算下，并支持双路径部署，把低延迟交互与可选的 replay-time refinement 结合，由单步学生对自己的草稿再加噪精修。在配对的 Minecraft 轨迹上，ForgeWM 在图像质量、与参考对齐的运动剖面一致、动作符号准确率与鼠标控制准确率上均领先参评系统，参考 LPIPS 也最低；同一四阶段配方可迁移到手柄控制的 FPS 玩法。replay-time refinement 在质量上匹配四步参考，同时相对从噪声重新生成，与真实经历的轨迹距离约为其三分之一。

Insight by AI ForgeWM 的核心价值在于把动作条件视频世界模型的少步生成拆成可组合的四阶段训练配方，并显式支持实时交互与高保真回放两条路径；同一流程在 Minecraft 与手柄 FPS 之间的可迁移性，意味着这条路线具备跨交互范式复用的潜力。
