OpenAI 向 Pro 与企业用户全量开放 GPT-6 Astra，并进入 API

OpenAI 在 X 上宣布 GPT-6 Astra 已面向 Pro、Enterprise 与 Business Premium 用户在 ChatGPT Work 与 Codex 中开放，同时也在 API 中上线。官方提示 Plus 与 Business 用户的覆盖还需要数天时间逐步推送；近期预告曾强调 Astra 的网络安全能力达到 Preparedness 框架的 Critical 级别。

Insight by AI Astra 先以受限形式开放、再按订阅档位与 API 同步推进，是 OpenAI 把高安全等级模型快速变现的典型路径，Critical 级别网络安全能力也使企业安全采购成为重要买单方。

深度跃迁提出具身基座模型新路线，演示对未见场景的自主应变

机器之心报道，深度跃迁团队展示了具身基座模型在未采集数据场景下的自主应变能力。实验中机器人手持爆米花准备放入微波炉，实验人员突然关闭炉门，机器人保持目标物不变，重新打开炉门后继续完成原任务。该报道强调，智能涌现的早期迹象已经在该类具身基座模型中出现。

Insight by AI 在训练分布外仍能保持目标与步骤连贯，是具身基础模型区别于纯模仿策略的关键标志；若该能力可稳定复现，将推动具身智能从脚本化示教迈向可泛化部署。

SemiAnalysis观点：OpenAI启动ASIC项目是合理战略

SemiAnalysis在X上发文称，OpenAI启动ASIC项目并投入数亿美元研发、在Hot Chips上展示、部署部分产品以制衡NVIDIA的策略是合理选择。评论指出，即便代号Jalapeno的芯片在大规模部署中表现不佳，OpenAI仍能从NVIDIA获得数十亿美元规模的额外资金与回购承诺。SemiAnalysis同时认为，若Jalapeno规模化表现良好，OpenAI的单位MW收入有望提升。

Insight by AI 这条X讨论反映OpenAI希望以自研ASIC降低对单一GPU供应商依赖，并通过技术路线分化向NVIDIA争取更优的算力采购与回款条款，凸显超大规模AI公司在算力议价层面的博弈升级。

AMD MI355x在AgentX部分交互区间TCO优于B300

SemiAnalysis在X上发文称，在AgentX基准上以总token数除以TCO计算时，最新提交的AMD MI355x结果在较低交互性区间优于NVIDIA B300。SemiAnalysis在文中向vLLM、AMD与LMCache工程师致谢，但未披露具体的TCO数值、交互区间边界与提交版本细节。

Insight by AI 该结果若经独立复现，将为AMD MI系列在Agent工作负载下的单位成本竞争力提供公开依据，并强化vLLM与LMCache在跨厂商推理栈中的枢纽地位。
@semianalysis_

SemiAnalysis解析Intel放弃EMIB转向UCIe-S的架构动因

SemiAnalysis在X上发文称，Intel在2027年Diamond Rapids CPU上放弃EMIB封装互连，核心目标是实现统一内存访问（UMA）：每个CBB内的CPU核心可单跳访问全部16条内存通道。为达成这一目标，需要通过基板中的UCIe-S在近端IMH下方布线延伸至远端IMH，信号走线长度约30毫米。相比之下，AMD Venice采用NUMA设计，内存通道分布在远程IOD上，文章未给出关于远端访问时延与带宽的对比细节。

Insight by AI Intel押注UMA以换取跨芯片一致内存语义，AMD则接受NUMA以换取更灵活的拓扑，两条路线分别面向通用HPC与云端高密度部署场景，将直接影响后续AI加速器—CPU配对方案。
@semianalysis_

英伟达 RTX 在 Blackwell 上为 vLLM 提供本地推理提速，最高 1.4 倍

vLLM 项目在 X 上转发英伟达 RTX 的本地 Agent 优化进展：RTX PRO 6000 Blackwell 跑 vLLM 性能提升约 1.2 倍；由两套 DGX Spark 组成的集群场景下提速最高可达 1.4 倍。此次更新聚焦 RTX 与 DGX Spark 的本地 serving 路径，但官方未披露对应的 batch、序列长度或模型规格。

Insight by AI DGX Spark 集群带来 1.4 倍提速说明 Blackwell 本地推理的瓶颈在多机互联而非单卡算力，本地 Agent 部署的性价比会随着小集群方案成熟而进一步上升。
@vllm_project

LeanStream：面向端侧 LLM 推理的推测-精化流式框架

论文针对端侧 LLM 推理中模型权重远超 DRAM 的瓶颈，提出 LeanStream 流式推测-精化框架。系统利用部分 GPU 结果渐进式精化计算、加载与缓存保留优先级，在 GPU 执行与存储 I/O 之间实现细粒度重叠。作者在移动与嵌入式平台上实现 LeanStream，在达到先前最优吞吐时，内存占用降低 4.8× 至 7.5×，token 生成吞吐再提升 1.6× 至 2.1×。

Insight by AI 端侧大模型推理的关键瓶颈已从单纯算力转向计算-I/O 协同；推测-精化配合部分结果回灌，为激活稀疏与权重卸载的协同调度提供了新的系统级解法。

Artificial Analysis 发布智能指数 v4.2，新增 AA-Briefcase 等更复杂任务

Artificial Analysis 在 X 上宣布 Intelligence Index v4.2 正式发布，作为 v5 之前的过渡更新，纳入了更复杂、更贴近真实场景的任务以及更多私有测试集以防刷榜。v4.2 的更新包括新增 AA-Briefcase 这一基于私有测试集的智能体知识工作评估，并引入 HelloSurgeAI 的 GDP.pdf 等新基准，但具体的指数得分与榜单变动尚未在公开证据中给出。

Insight by AI 在 GPT-6 Astra、Claude Fable 5.1 等模型密集刷榜的窗口期，Artificial Analysis 用私有测试集和更复杂任务把“刷榜成本”抬高，会让后续模型对比更依赖第三方基准而非厂商自测。

Anthropic 公布 Claude 完成费马大定理形式化证明

Anthropic 在 X 平台发文称，数学证明的正确性核查往往耗时数年，借助 Lean 等计算机证明助手进行形式化是已知路径之一。上个月，Claude 完成了费马大定理的首次形式化证明，这是迄今最大规模的 Lean 项目之一。Anthropic 表示，这一任务是该领域专家原先预期需要多年才能完成的工作。

Insight by AI 形式化数学证明是检验 LLM 长程推理与符号操作能力的高难度试金石；若 Claude 此次结果可被社区复现，将为大模型在科学验证场景的应用提供新的能力锚点。
@anthropicai

Puffin-World：联合物理、几何与外观的统一多模态 3D 世界模型

论文提出 Puffin-World，一种统一多模态架构，将物理理解、空间仿真以及 3D 世界生成与重建整合在同一模型中，不依赖外部离线模块。框架将物理（重力场与纬度）、几何（深度）和外观（图像）三种原生世界状态与统一 Omni-Camera 表达联合建模，并提出跨未来帧传播物理动态的策略。为支撑复杂场景训练，研究构建了 Puffin-16M 数据集，包含 1500 万条视觉-语言-相机三元组与 100 万条多样化运动轨迹，并已开源代码、模型与数据集。

Insight by AI 将物理、几何与外观纳入同一生成过程，是世界模型走向可交互闭环的关键一步；1500 万级三元组与 100 万级轨迹的开源，也降低了原生 3D 状态建模的复现门槛。
HuggingFace Daily Papers

HarnessDev：将评测单元从任务输出转向可运行 Agent 基础设施

论文指出，Agent 能力日益依赖模型外的执行基础设施，即 Agent harness；仅调整 harness 而固定模型权重即可显著改变任务表现。作者提出 HarnessDev 基准，把评测对象从任务输出转向可运行基础设施，分 Creation（从最小种子构建完整执行系统）与 Evolution（基于下游执行反馈迭代修订 harness）两阶段。Creation 阶段覆盖六款创建者 LLM、四个领域、五个下游基准共 2207 个独立实例，结果显示在代码与搜索/研究任务上生成的 harness 仍显著落后于成熟人工参考，而在写作与机器学习实验任务上可匹配或超越，执行成本差异显著。

Insight by AI 把 harness 本身作为评测对象，能区分模型本身能力与执行层增益的来源；Evolution 阶段收益不稳定且跨模型迁移有限，说明 harness 与执行模型的耦合度比预想更高。
