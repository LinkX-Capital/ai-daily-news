01 / Data moat

趋势一｜数据：新的护城河

AI 竞争的核心正从算力迁移到数据，而数据的真正瓶颈是人类隐性知识。独家数据、专家工作流与可交互 RL 环境正在成为新的系统资产。

从公开语料走向人类隐性知识

算力可以用资本堆叠，也正因同类芯片与集群而逐渐商品化；高质量数据却无法由同质化基建解决。过去模型“惊人地相似”，是因为训练在同一个公开互联网上。公开数据耗尽后，训练数据的分布将决定模型最终能力与行为，独家、垂直、具身与隐性数据将推动模型从趋同走向分化。

核心判断：真正的瓶颈不是还能抓取多少网页，而是能否工业化捕获存在于人脑、组织流程与边缘案例中的“互联网暗物质”，并把它转化为可交互、可验证的 RL 环境。
DATA-LIMITEDTACIT KNOWLEDGERL ENVIRONMENTSO-RING

01 · 约束迁移：从算力受限到数据受限

算力靠资本可堆，但高质量数据不能。未来 3—5 年的关键变量，是模型公司能否摆脱相同公开数据分布，建立独家、私有且持续更新的数据供给。

02 · 护城河迁移：模型从趋同走向分化

架构、优化器与超参数更多影响训练效率；决定模型最终收敛为何种能力与行为的，是训练数据分布。只依赖公开语料的模型层公司将加速同质化。

03 · 瓶颈实质：隐性知识的工业化捕获

剩余知识存在于专家头脑、企业私有存储、未记录流程和边缘案例中。数据问题因此变成专家网络的组织问题；RL 的瓶颈则落到“软件 + 任务 + 验证器”构成的环境。

04 · O-ring：数据价值随模型变强而递增

不同投入是互补关系。当前置能力到位后，补齐最后 1% 数据可能带来“基本可用 → 完全替代”的跃迁，因此高质量 Agent 数据与评测不会快速商品化。

突破数据瓶颈的两条路径

“数据不够”其实包含两个不同问题：能否生产更多独特经验，以及能否从每次昂贵的环境交互中学到更多。

扩大供给：把隐性知识转成可训练经验

解决的是“新的高质量数据从哪里来”。关键不是继续抓网页，而是把专家判断、企业流程和真实交互转化为任务、评测与可执行环境。

PATH B · REDUCE DEPENDENCE

降低依赖：提高每次数据与环境交互的训练价值

解决的是“同样的数据能否产生更多有效更新”。目标是减少重复采样和同题多轨迹，把高成本、长时延环境中的每条轨迹都利用起来。

03

02 / Agent infra

趋势二｜Agent Infra：从资源调度走向任务级可靠性与自治执行

以 Modal 的实践为线索，模型推理、后训练、强化学习与生产级 Agent 正形成不同于传统 Web 服务的新型工作负载。

从 Modal 的实践看新一代 Agent Infra

模型推理、后训练、RL 与生产级 Agent 已形成不同于传统 Web 服务的新工作负载。Modal 正从自定义模型的多区域弹性推理和沙箱切入，向中等规模后训练、持久化状态、网络与安全、可观测性，以及跨 17 家云和裸金属供应商的容量调度扩张。

核心判断：Agent Infra 的本质，是把传统云从“人类操作资源”改造成“自治软件执行任务”的系统。长期平台机会不只是更快启动沙箱，而是围绕任务形成独立的运行时控制层。

WHY NOW

新一代 Agent Infra 为什么必要

必要性并非来自单一的“沙箱需求”，而是工作负载、任务生命周期与基础设施操作者同时发生变化。

LOAD SHAPE负载从稳定服务变成弹性组合

多区域推理、短周期后训练与 RL / 评测的突发并行，需要平台快速组合 CPU、GPU、存储与网络；峰值可扩展到约 10 万个沙箱。

TASK LIFECYCLE任务从短进程变成长轨迹

生产级 Agent 会读写文件、安装依赖、调用工具并持续重试，因此状态、安全、恢复与审计必须贯穿整个任务周期。

NEW OPERATOR操作者从开发者变成 Agent

API、CLI 与日志不仅供人查看，还要让 Agent 完成“运行—观察—定位—修改—重试”的自主闭环。

REBUILD

Agent Infra 需要重构的不只是沙箱，而是整个任务控制层

传统云继续提供计算、存储与网络资源；真正需要新增的是中间的任务控制层，将新型工作负载转换为可隔离、可恢复、可治理的执行轨迹。

CAPABILITY STACK

核心能力需求

能力栈可以压缩为四个不可缺的系统支柱：运行时、控制面、安全边界，以及任务级可靠性与容量管理。

01 · RUNTIME有状态、可恢复的运行时

隔离执行、持久化文件系统、快照、多容器、后台任务与完整生命周期管理。

02 · CONTROLAgent 原生控制与可观测性

机器可操作的接口、结构化上下文，以及由日志驱动的自主诊断、修复与验证。

03 · SECURITY确定性的任务安全边界

最小权限、临时凭证、出站网络控制、数据隔离与可追溯审计。

04 · RELIABILITY任务轨迹与跨云容量管理

检查点、部分重试和环境重放，与 CPU / GPU 的跨云异构调度协同，保证长任务以合理成本完成。
