模型前沿

MiniCPM5-2B 在 Artificial Analysis 智能指数 v4.2 中取得 15 分

OpenBMB 发布的 MiniCPM5-2B 在 Artificial Analysis Intelligence Index v4.2 上得分 15，是总参数 4B 以下的开源权重模型中的最高分。MiniCPM5-2B 是一款 2.6B 参数的稠密推理模型，支持文本输入与文本输出，采用 Apache 2.0 协议发布。OpenBMB 是开源 AI 团体，旗下 MiniCPM 系列主打高效小模型。

Insight by AI 4B 以下参数段位的开源模型智能水平被 MiniCPM5-2B 刷新，意味着高效小模型阵营在推理任务上的竞争力进一步上行，对边缘与端侧部署场景具有直接参考意义。
@artificialanlys

芝诺机器人发布全球首个协作具身智能基础模型

据机器之心报道，芝诺机器人发布了被其称为“全球首个协作具身智能基础模型”的新成果。该工作把行业焦点从提升单体能力转向多机/多智能体之间的协作范式，尝试在具身智能持续进化这一命题上探索协作型的基础模型路线。原报道围绕具身智能如何借助协作实现能力跃迁展开。

Insight by AI 协作具身基础模型把多智能体协同视为新的底层能力，而非单体的能力堆叠，可能重新定义具身智能的数据闭环与评测维度。

vLLM 稳定版 Day-0 支持 MiniCPM5-2B

vLLM 项目宣布在稳定版中 Day-0 上线对 OpenBMB MiniCPM5-2B 的支持。该模型为 2.6B 稠密架构，原生支持 131K 上下文，可在同一 checkpoint 切换 Think 与 No-Think 模式，并通过 vLLM 的 minicpm5 parser 提供工具调用能力。vLLM 同时感谢 OpenBMB 沿用标准 LlamaForCausalLM 结构、并把训练数据与权重同步开源。

Insight by AI 推理引擎对新模型做到 Day-0 适配，并以最小架构改动复用 LlamaForCausalLM，体现了小模型生态在权重开放与训练数据透明上的成熟度正在收敛。

SemiAnalysis：TPU 推理外溢提速，InferenceX 显示每美元性能提升最高达 50%

SemiAnalysis 在 X 平台发文称，TPU 推理外溢正在全面加速，旗下 InferenceX 基准显示在特定配置下每美元性能最高可提升 50%。文章同时梳理了 TPU 栈快速外部化、客户群持续扩张以及 Ironwood（TPUv8i）在缩小 CUDA 护城河方面的进展。该推文以一张信息图链接收尾，未在证据中给出更多性能数字或客户名单。

Insight by AI 把 TPU 与 CUDA 的竞争直接量化为「每美元性能」和「推理外溢速度」，意味着 SemiAnalysis 认为 TPU 的真正威胁不在训练峰值，而在推理性价比与企业客户的迁移门槛。

AMD 称在 19 天内通过软件优化把 vLLM 在 MI355X 上的性能提升 11 倍

SemiAnalysis 在 X 平台发文称，AMD 在不到 19 天的时间里，将 vLLM 在 MI355X 面向 Agent 负载上的性能提升至原来的 11 倍，相关基准使用 MiniMax M3 模型。此次提升全部来自软件层面的优化，重点改进了长上下文注意力算子，并辅以其他优化项。SemiAnalysis 以此说明「一次购入硬件、持续通过软件优化获得性能提升」是 ROCm 栈的核心卖点。

Insight by AI 11 倍来自纯软件迭代，把 ROCm 的竞争叙事从硬件参数转向「时间维度上的性能增量」，直接挑战了 CUDA 生态以成熟软件栈构筑的迁移成本壁垒。
@semianalysis_

vLLM 通过 TT Plugin 将 Tenstorrent 加速器纳入推理后端

vLLM 团队发布 vLLM TT Plugin，将 Tenstorrent 加速器以 out-of-tree 平台插件的形式接入 vLLM；只要环境中可导入 ttnn（TT-Metal），Tenstorrent 硬件就会被自动注册为 vLLM 平台，对外仍保持 OpenAI 兼容 API 与请求格式。文章指出，Tenstorrent 的网格架构与 GPU 差异显著，因此插件内部按阶段（prefill/decode）调度、在 Galaxy 上采用单进程数据并行、并在采样环节优先在设备端执行并保留主机端回退，解码阶段的重叠则通过异步读回而非异步执行模型实现。

Insight by AI vLLM 把 GPU 假设之外的多核网格加速器纳入插件体系，意味着 LLM 推理引擎正在被抽象成可承载多种硬件拓扑的调度框架，国产/非 CUDA 后端的接入门槛被显著压低。

研究关注

论文提出 Random Attention：以随机淘汰替代 KV cache 评分，在 vLLM 上吞吐提升 32–43%

论文指出大语言模型在长链推理时 KV cache 占用成为严重内存瓶颈，并质疑既有压缩方法普遍采用的“为每个缓存 token 打分并保留高分”这一选择信号。作者提出 Random Attention：在每个注意力头内部对 prompt 之外的 token 进行均匀随机淘汰、不计算任何分数；在四个模型与六项推理任务的对照中，其表现与最强既有淘汰器持平，并在 vLLM 部署中相对后者实现 32–43% 的吞吐提升。作者将这一现象归因于 prompt 才是 cache 中最脆弱的部分，而推理 trace 在文本层和注意力头层都自带冗余，因此一旦 prompt 安全，随机抽样即可保留足够多的关键信息。代码已在 SalesforceAIResearch 名下 GitHub 仓库公开。

Insight by AI 该工作把 KV cache 压缩的争论从“如何更好打分”拉回到“是否需要打分”，对工程实践的直接含义是：推理服务可以省去打分开销与对应实现复杂度，靠结构冗余换取吞吐；但其在长上下文极端分布上的稳定性仍需独立验证。
HuggingFace Daily Papers

论文 SharedSAE：用一份共享特征字典同时解释多个语言模型

论文针对稀疏自编码器（SAE）需要为每个模型单独训练并重复标注潜在特征的问题，提出 SharedSAE：由跨模型共享的特征字典加上各模型专属的编解码器组成。作者表示，与丢弃激活幅值、并要求推理时同时持有所有模型的既有方案不同，SharedSAE 仅对选择分数做归一化以保留幅值，并使用模型 dropout 支持单模型推理。该方法在四个 1B 规模、来自不同家族与分词器的基础语言模型上训练，平均解释方差达到专用 SAE 的 96.6%。论文还报告其潜在激活在跨模型相关性上比事后对齐的独立 SAE 高 1.8 倍，潜在描述可在模型间迁移，字典冻结后新模型仍能以接近专用 SAE 的重建质量适配。

Insight by AI SharedSAE 把“可解释性资产”从“按模型复制”转向“按字典共享”，降低了多模型机制研究的标注与训练成本，但也意味着跨模型描述的有效性需要新的评测标准来检验。
arXiv cs.LG

论文以缓存级干预拆解混合语言模型：注意力负责“查什么”，循环状态负责“怎么答”

论文针对同时使用注意力与固定大小循环状态的混合语言模型，提出两种缓存级干预：split-prefill 在已预填充的上下文上只保留 KV cache 或只保留循环状态再生成答案；state-swap 在单次前向中把一份上下文的 KV cache 与另一份的循环状态组合使用。作者在 Qwen3.5 与 Falcon-H1 上观察到两通道功能高度分化：精确检索只依赖注意力通道，在仅保留循环状态时准确率塌缩至零；而输出语言与人设风格则主要依赖循环状态，仅保留 KV 时语言准确率跌至约 1%。state-swap 实验进一步表明答案的取值随 KV 侧改变、语言风格随循环侧改变。论文还指出循环状态能够接受并未出现在上下文中、但与已见词共享语义或部件的词。

Insight by AI 该工作将混合架构的“两条记忆通道”从工程取舍提升为功能划分，为后续 KV/recurrent 比例、压缩策略与可控生成提供了清晰的因果依据，但具体到不同模型族是否仍成立还需扩展实验。
arXiv cs.CL

论文提出数据融合框架：用风洞 PSP 测量“矫正”CFD 训练的气动代理模型

论文指出基于高保真 CFD 数据训练的深度学习代理模型虽能高精度复现数值预测，但与实验观测之间存在系统性偏差。作者提出一个不修改代理模型参数的实验矫正框架：先用 2,300 组 NASA CRM 翼身构型的高保真 CFD 仿真训练 Geotransolver 代理，覆盖几何变化、马赫数 0.70–0.85 与迎角 0–4 度，再以两 freestream 马赫数（0.70 与 0.85）下与 CFD 网格空间对齐的风洞 PSP 测量训练一个矫正网络，学习代理预测与实测表面压力分布之间的偏差。论文报告在 Mach 0.85 下，矫正显著改善了翼面吸力峰、激波位置与后续压力恢复段的吻合度，并降低了预测误差超过 0.05 Cp 的湿表面积占比；在留出迎角上，矫正后的代理与测量的差距落在测量 Cp 量程的 2.3–2.7% 之内。

Insight by AI 该框架把“仿真训练 + 实验矫正”拆成两阶段、保留原代理参数，对于昂贵的高保真仿真领域是一种低成本的工程落地路径，但矫正网络对未见几何与工况的泛化边界仍需进一步验证。
arXiv cs.LG
