模型前沿

阿里 Qwen 团队发布 Qwen3.8-Flash 预览版，开放权重并预告 Qwen4 架构

阿里 Qwen 团队在 X 平台公布多模态 MoE 模型 Qwen3.8-Flash，作为下一代 Qwen4 架构的早期预览并以开放权重形式发布。模型总参数 125B，含 51B N-gram 嵌入，每 token 仅激活 6B 参数，生产版本将通过 QwenCloud API 提供，输入/输出定价分别为 0.16 美元/百万 tokens 与 0.47 美元/百万 tokens。

Insight by AI Qwen3.8-Flash 以“百亿参数 / 6B 激活 + N-gram 嵌入”组合切入推理侧成本曲线，本质上是把 Qwen4 路线图提前以开源权重形态对外暴露，倒逼闭源多模态模型在 API 价格上做出回应。
@alibaba_qwen

智谱发布 GLM-5.3-Flash，定位原生多模态 320B 模型

智谱在官方 X 账号宣布上线 GLM-5.3-Flash，主打高性价比与领先能力。模型为原生多模态，支持 1M token 上下文窗口，采用 320B 总参数 / 18B 激活参数的 MoE 架构，并以 MIT License 开源权重。官方确认该模型此前的预览版本为 Ox Alpha，推理全程运行在中国 AI 芯片上，并已通过官方博客、权重仓库与 API 等渠道同步开放。

Insight by AI GLM-5.3-Flash 把此前引发关注的匿名模型 Ox Alpha 收编为正式版本，意味着围绕其血统的猜测告一段落；结合 MIT 开源与国产芯片推理两条信息，智谱正在用「开源 + 本土算力」组合切入性价比市场。
@zai_org

Google 发布 Gemini 3.5 Transcribe 系列语音转录模型

Google 推出 Gemini 3.5 Transcribe，在 AA-WER 基准上以 2.6% 排名第 5。该系列同时包含面向流式音频的 Gemini 3.5 Transcribe Live，在语音结束后 0.40 秒的 Streaming 场景下 AA-WER 为 4.0%。其中 Gemini 3.5 Transcribe Live 通过 Live API 提供持续流式识别，Gemini 3.5 Transcribe 通过 Interactions API 处理预录制音频。

Insight by AI 将流式与离线 API 拆分为两条产品线，显示 Google 在把不同延迟档位的语音转写作为独立可计费 SKU 来运营；2.6% AA-WER 进入前 5 与 0.40s 流式窗口的组合，是其在实时语音 Agent 配套能力上对标 OpenAI 与 AssemblyAI 的关键筹码。

对比此前的 GigaBrain-0 系列以及包括 π_{0.5} 在内的已有 SOTA 模型，作者称 GigaBrain-0.7 在零样本能力、语言条件指令跟随与后训练任务成功率上均有显著提升；其在自有 Maker H01 平台与主流机器人形态上覆盖了家庭与工业两类场景。作者表示将开源全部训练代码与预训练权重。

OraRL：把标注当 rollout，提升视频多模态模型 RL 后训练效率

论文 OraRL 研究视频多模态大模型在后训练阶段的强化学习效率与可扩展性，提出让数据标注以 oracle rollout 身份进入 on-policy 组、直接作为正样本优化目标的方案。论文将直接并入 oracle 所引发的组基线抬升与优势翻转现象命名为 advantage inversion，并据此设计了解耦优势估计器：策略 rollout 决定去 oracle 基线，oracle 与策略之间的差距分别调制方向增益与一个独立的 detached oracle 优势。论文还采用符号平衡剪枝，使 OraRL 每步时间仅为 SFT 的 2.2 倍，低于 GRPO 加思维链方案的 4.9 倍。Video-ORA-9B 无需思维链时解码耗时 130 毫秒，相较 4780 毫秒显著压缩；在多项基准上相较各自此前最优模型，时序 mIoU 由 62.5 提升到 66.0、跟踪 AO 由 73.0 提升到 78.2、分割由 64.3 提升到 70.4、三项空间智能基准宏平均由 51.0 提升到 56.1；VSI-Bench 上取得 73.1，GPT-5 为 55.0、Gemini-3-Pro 为 55.1。

Insight by AI 把标注直接当作正样本优化目标，是用数据质量对冲 RL 采样成本的一条新路径；解耦优势估计器与符号平衡剪枝的组合，把视频 MLLM 后训练从「靠 CoT 堆 rollout」转向「靠高质量样本控算力」，对 9B 级别模型的工业落地尤其有意义。
HuggingFace Daily Papers

Game2World：分离游戏 UI，把野生游戏视频转化为世界模型训练数据

论文提出 GameUI-Taxonomy 与全栈框架 G2WEngine，目标是剥离野生游戏视频中与游戏世界纠缠在一起的屏幕空间界面，避免其给世界模型训练引入特定游戏的偏差与无关动态。G2WEngine 可从真实游戏视频中自动抽取可复用 UI 资产，并在干净画面上合成时序一致的 UI 叠加。基于该框架构建的数据集 Game2World 包含 96K 配对合成视频与来自 303 款游戏的 1079 段真实片段，资产库覆盖 21 个 UI 类目、共 5132 个经过核验的元素。论文同时提出无掩码的 GameCleaner 模型，直接识别并移除多种 HUD 元素同时保留背景与时序动态；在合成视频 UI 移除任务上其 AAR 平均 95.36，比最强时序掩码基线高 57.3%，野生视频 AAR 80.05 且背景保留度 99.8；用 Game2World 训练的世界模型 VideoReward 较 UI 叠加数据训练版本提升 6.83%。

Insight by AI 用结构化 UI 资产库 + 无掩码编辑模型，把野生游戏视频改造成可用世界模型训练数据，意味着互联网规模的现成素材第一次有了一条可复用的「去杂质」流水线，对游戏出身的世界模型是基础设施级别补全。
HuggingFace Daily Papers

扩散生成中的「物种形成」：在紧致黎曼流形上刻画分支动力学

论文围绕紧致黎曼流形上扩散模型的「物种形成」（speciation）现象展开理论分析，把这一过程刻画为演化概率密度临界点的分岔，并以谱热核表示把流形几何的角色显式化。论文借助 Poincaré-Hopf 与 Morse 理论，对分数均衡点的数量与类型施加全局约束，揭示由拓扑决定的几何模式；对热核混合情形证明了一般化的物种形成事件具有一维临界核且符合 A2 折叠普适形式，pitchfork 等对称分岔只在非一般化对称配置下出现。论文还给出双峰混合与正则单形的几何依赖物种形成时间估计，并在球面上以 von Mises-Fisher 混合分布示例观察到了 pitchfork、鞍结分岔与多层级物种形成。

Insight by AI 把生成过程放进紧致黎曼流形并显式引入拓扑约束，是对「为什么扩散模型会分出清晰类别」的底层回答；这套框架未来若与几何感知的 score 估计结合，可能会影响流形上的少样本生成与可控生成研究。
arXiv cs.LG
