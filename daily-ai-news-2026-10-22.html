Tesla 启动 Optimus 加州量产，并计划 2027 年末达到每周 2 万台

Tesla 已在加利福尼亚州弗里蒙特工厂启动 Optimus 人形机器人生产，所用制造空间此前用于生产电动车。公司称，产线上下线的机器人是其制造的首批达到生产质量的产品，当前制造流程已适合商业产品。Tesla CEO Elon Musk 将现阶段定义为早期量产，并表示爬坡过程会较慢且出现波动，同时称公司计划到 2027 年末实现每周生产 2 万台。

Insight by AI Tesla 已把 Optimus 从原型推进到生产质量验证阶段，但安全、可靠性和长时工作能力仍需继续调整，每周 2 万台仍是公司披露的远期目标，不能视为已实现的产能。
TechCrunch

Anthropic 发布 Claude Duet 研究预览：主动式 Agent 应用，主动汇报待办并在获准后代为行动

Anthropic 推出独立应用 Claude Duet 的 research preview（面向美国 Pro/Max 用户候补）：基于 Claude Opus 5.5，定位「主动式 Agent」——每天早晨推送跨连接应用的要点简报，全天盯守 Gmail、Slack、QuickBooks 等应用、只在需要时打扰用户；任务从排会、开发票到搭 dashboard 都可在自带虚拟机的后台浏览器中执行，用户离开也继续跑，完成后通知。付款、发消息、签文件、删除等动作执行前必须经用户确认，证券交易与账户间转账即使批准也被禁止；支持 Marketplace 6000+ 连接器，可用 Stripe Link 虚拟卡代付。敏感信息由专用分类器把关，信用卡号与身份证件默认拒发。

Insight by AI 从「你去找 AI」到「AI 来找你」，Duet 是大厂里第一个做成独立消费级应用的 proactive agent——它的信任设计很清楚：判断力（何时打扰、何时请示）加一张明确的行动禁区清单；研究预览与主应用共享额度、独立于 Claude 主站，暗示其形态验证后可能并回主产品。

OpenAI 前沿模型与 Codex 将登陆 Google Cloud：进入 Model Garden，可计入 GCP 承诺消费额

OpenAI 宣布与 Google Cloud 合作，将前沿模型与 Codex 智能体工作流引入 Google Cloud 的 Model Garden，通过 Google Cloud Marketplace 交易，未来几周上线；已承诺 Google Cloud 消费额度的企业可将采购计入 GCP 承诺额。模型还将进入 Google Antigravity 与 Gemini Agent，让企业按任务选用不同模型。官方声明末尾特别注明「微软仍是 OpenAI 的主要云合作伙伴」。

Insight by AI 曾是 Azure 独占招牌的 OpenAI 模型摆进了对手的货架：对 Google Cloud 是把最抢手的 SKU 补进 Model Garden，对 OpenAI 则是分发渠道多中心化的又一步；「计入 GCP 承诺额」这个细节说明双方争夺的是已锁定云预算的企业钱包。

MiniMax 与 SGLang 合作：M3.1 Flash 搭配 Omni 交互运行时，可打断语音 Agent 单卡 16 并发会话

MiniMax 与 SGLang 团队合作，用 M3.1 Flash 配合新发布的 SGLang Omni 统一交互运行时，探索可打断、可改向的语音 Agent——从「问、等、听」转向用户可随时打断纠正的持续对话。SGLang Omni 用图（graph）组合模型能力与交互控制、用持久会话协调生命周期，统一支持原生全双工、轮次式与级联三种交互架构；其评测显示级联方案（Qwen3-ASR→Qwen3.8-27B→Qwen3-TTS）在单张 H200 上支撑 16 路并发会话，用户打断后平均 0.17 秒停止、1.32 秒开始回应。三种架构各有取舍：原生全双工模型最擅长应对旁话与背景人声，级联方案漏读率最低（0.4%），轮次式的语音自然度与一致性最好。

Insight by AI 语音 Agent 的竞争正从「模型」下沉到「运行时」——谁该说话、被打断后历史如何截断、播放进度如何回写，这些系统问题决定体验上限；SGLang 把三种架构放进同一评测框架等于给行业提供了可复现的交互基准，MiniMax 借此把自家模型嵌进下一代 voice agent 的参考栈。
@MiniMax_AI / SGLang Blog

Mistral 与 NVIDIA 深化工程 AI 合作：将开放物理与 CAE/EDA 智能体基准，Le Chonk 月底开源权重

Mistral 与 NVIDIA 宣布合作开发新一代 AI 原生工程工作流：结合 Mistral Large 4 与 Mistral 的数据生成、物理建模管线，用 NVIDIA CUDA-X 库与 Warp 加速仿真，并集成 Omniverse 做 GPU 加速 3D 场景生成；双方将发布公开基准与开放数据集，标准化评估物理模型以及 CAE/EDA 场景中的智能体能力（工具使用、多步工作流、技术正确性、执行时间与算力成本）。合作建立在共同开发 Mistral NeMo、Nemotron 联盟等既有关系上；Mistral 同场披露 Mistral Large 4（Le Chonk）约 1T 总参/49B 激活、由 3800 张 Grace Blackwell 训练，权重计划10 月底发布，其算力路线图目标 2030 年达 1GW。

Insight by AI 「物理 AI」叙事正从机器人扩展到 CAE/EDA 仿真这条更安静的赛道——仿真速度直接限制工程迭代节奏，开放基准则意在抢占评估标准话语权；对 Mistral，这是把开源权重模型嵌入工业软件栈的入口，与其欧洲主权算力扩张互为支撑。

Recursive 发布首个模型 Flint：40B MoE 本地编码模型，自称 4 个月由自动科研系统造出

Richard Socher 创办的 Recursive 发布首个模型 Flint：40B 总参/2.5B 激活的 MoE，主打本地设备上的 agentic coding，权重以 Apache 2.0 开源。官方称其在 SWE-Bench Pro v2、Terminal-Bench 2.1、SWE-Bench Verified 等基准上领先 50B 以下 MoE 模型，编码表现对标 25-40B 稠密模型且快 5 倍以上；经全栈推理优化，在 M4 Pro MacBook Pro 上生成 125+ tokens/s、64GB RTX Spark 上 150+ tokens/s，支持 512K 上下文。公司强调 Flint 由其自动科研系统 Eureka Machine 参与了从架构搜索、量化配方到 Metal megakernel 的几乎全流程开发，小团队从零构建耗时不到 4 个月。

Insight by AI Flint 真正的卖点是「模型是自动科研系统的输出」——4 个月、小团队、基准领先，这是 Eureka Machine 的一次公开能力证明；若自动 R&D 可持续复现，模型开发的成本结构将被改写，「用模型造模型」从口号变成工程流程。
Recursive / @RichardSocher

Coco Labs 发布分层设计模型 Vyb：字体还原 90.3% 超图像模型，编辑只动该动的 11.9% 像素

Coco Labs 发布其称为首个「理解品味」的设计模型 Vyb：不做整图像素生成，而以图层（layer）构造设计——文字保持文字、图形保持矢量、照片保持像素，并为此创造了面向 AI 的设计语言 Cocolang，分层结果可无损导出 Figma。官方评测显示：145 个 Google 字体的形状匹配达 90.3%（ChatGPT Image 2.5 为 76.0%、Muse 50.9%，测量噪声上限 94.4%）；指定颜色还原误差为 0；文本改色类编辑平均只改动 11.9% 的像素（对比模型普遍改动 92%-99%），即编辑不波及用户素材。

Insight by AI 图像生成模型把设计压平成像素的那一刻就输了保真度——Vyb 用图层加专有语言绕开矛盾，瞄准的是 Canva/Figma 生态的自动化缺口而非通用文生图；90% 对 76% 的字体还原差距，在字体即资产的品牌场景里是决定性的。

JOLT：同一模型兼任教师与学生，MATH 以 6.5 倍更少训练 token 匹配 GRPO

Perplexity 发布后训练方法 JOLT，让同一个模型分别承担教师和学生角色。教师模型生成的反馈可由学生模型用于学习，从而在同一架构内完成训练闭环。JOLT 在 MATH 上匹配了 GRPO 的准确率，所用训练 token 少 6.5 倍。

Insight by AI 单模型双向训练可能减少教师与学生分离带来的额外开销，但现有证据仅覆盖 MATH，准确率匹配能否扩展到其他任务仍需进一步验证。
