Insight by AI 在与 Cerebras 这类推理芯片合作的前提下，把推理速度作为可售卖维度单独发布，反映 OpenAI 在 API 层把“速度/成本”做成与“智能”并列的差异化指标。

SHAPER：冻结模型参数，通过演化技能与 harness 实现具身智能体自我进化

arXiv 论文 2608.11350 提出了 SHAPER 框架，用于在冻结基础模型参数的前提下、面向目标环境改进非参数化的具身智能体系统。该方法通过环境 rollouts 演化可复用的技能库以及上下文-代码 harness，并由同一个冻结模型同时担任规划器与优化器。论文在 VLABench 和 ESI-Bench 上对比了纯执行、监督微调以及无验证器选择与投票等测试时扩展基线。

Insight by AI 在模型训练成本高、奖励信号稀缺的具身场景，让同一模型自我优化外部 scaffolding 比不断重训模型更经济，也更适合 API 受限的固定接口机器人。
arXiv cs.CL

论文提出把词表大小当作与部署环境耦合的基础设施参数

arXiv 2608.11361 把 LLM 词表大小视为部署阶段仍可调整的基础设施参数，并给出生命周期总成本形式 C_lifecycle(V) = C_train(V) + λ·C_infer(V, B)，其中 λ 为推理量、B 为批大小。论文在 A10G 与 A100 两代 GPU 上做对照实验，得出三点结论：推理最优词表随批大小变化可达 16 倍，B=1 时为 32k、B≥64 时升至 524k，主要由 V×d 解嵌入矩阵读取均摊驱动；在 1.3–2.3B 规模下质量（bits per byte，BPB）在 V=65k 处最优，呈现规模相关的偏好；在生产部署中生命周期最优词表与训练最优词表最大相差 16 倍。在最优区间内 BPB 波动小于 2%，因此词表选择在该论文测得范围内近似为纯系统优化。论文据此给出容量规划建议：端侧部署（B=1）宜用 V≈32k；数据中心服务（B≥64 且 λ≥10）宜用 V≈131k–262k。

Insight by AI 把词表从训练超参提升为部署阶段可再调的容量规划变量，意味着同一基模可在不同服务形态下重新选择词表以摊薄解嵌入成本，这对端侧与云端协同的多形态发布是一条可直接量化的工程抓手。
arXiv cs.LG

AdvFD：用对抗式 Fréchet 距离损失改进一步式生成器后训练

论文将 Fréchet 距离作为生成器后训练阶段的分布级目标，针对现有 FD-Loss 使用静态预训练特征空间、易出现 Fréchet hacking 的问题，提出对抗式 Fréchet 距离（AdvFD）。AdvFD 在原静态 Fréchet 目标之外引入一个对抗式学习的可学习表征，由判别器最大化真实与生成样本在该表征下的 Fréchet 差异，生成器则在得到的自适应特征空间中最小化同一差异。为避免对抗表征通过特征放大轻易抬高目标值，作者进一步引入 real-feature whitening，对真实特征的尺度与协方差几何做归一化以稳定 min–max 优化。论文报告在 JiT 与 pMF 两种骨干、不同模型尺度下，AdvFD 对一步式生成器后训练均带来一致改进。

Insight by AI AdvFD 把分布匹配与样本级去噪损失解耦，并把特征空间从固定来源扩展为对抗来源，缓解了单一 FID 类指标被针对性“刷分”而其他特征空间退化的风险，对一步式蒸馏/后训练的可控性是一个更稳的目标函数选项。
HuggingFace Daily Papers

论文首次将扩散语言模型用于无损文本压缩

arXiv 2608.11249 研究无损文本压缩问题，指出近期基于神经语言模型的方案在文本与代码上对 zstd、gzip、bzip 等通用压缩器具有显著压缩比优势，但受限于自回归每步一个符号的吞吐瓶颈。论文首次在无损神经文本压缩语境下引入扩散语言模型（DLM）替代自回归 LLM，以期突破每步一符号带来的吞吐限制。论文针对 DLM 在无损压缩中的算法挑战设计策略——DLM 允许每轮前向独立决定编码符号的数量与位置——并在 enwik8 基准上与基于 LLM 的方案以及通用压缩器对比。论文报告该框架在无损文本压缩上推进了当前最优水平，并指出 DLM 仍属较新范式，后续进展或带来进一步提升空间。

Insight by AI 若 DLM 路径成熟，无损压缩可同时获得神经方案的压缩比与并行解码吞吐，对大规模语料与代码归档是一类可量化的存储侧收益，但其工程实用性仍取决于 DLM 在严格无损条件下的解码时延与一致性。
arXiv cs.CL
