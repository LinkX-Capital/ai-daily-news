Sand.ai 发布并开源千亿参数 MoE 视频生成模型 MAGI-2 Preview

8 月 5 日，Sand.ai 发布并开源 MAGI-2 Preview，统一音视频生成模型；文本、视频和音频输入同一套 Transformer，画面与声音由同一主干共同生成，模型总参数规模约千亿级。该模型定位是降低长视频生成成本，对外强调性价比。

Insight by AI 把视频与音频放进同一主干并开源千亿 MoE，是把多模态生成从两条独立管线向统一架构收敛的一次明确尝试。

ToolArtist：用统一多模态模型把工具调用与图像生成纳入同一策略

论文指出，文生图模型虽能产出视觉效果出色的图像，但在开放世界任务中受限于复杂语义理解、多步推理与外部知识的整合；现有 Agent 化尝试要么套用固定流程，要么仅把部分流程交由 Agent 控制，导致推理、工具调用与图像生成无法被同一策略协同调度。ToolArtist 基于统一多模态模型（UMM）后训练得到完全 Agent 化的图像生成模型，在同一策略内动态协调推理、外部工具使用与原生图像生成。监督微调阶段为教师 Agent 配备搜索工具与图像生成工具，并把收集到的轨迹转写为 UMM 兼容格式，隐藏图像生成工具本身、保留生成图像；强化学习阶段针对 UMM 构建 Agent RL 基础设施，并提出 Reason-Act-Draw GRPO（RAD-GRPO），通过意图奖励与质量奖励联合优化。实验显示，将整个开放世界图像生成流程交由单一 Agent 策略调度，优于固定流水线或仅部分 Agent 化的方案，作者开源了训练数据与整套后训练基础设施。

Insight by AI ToolArtist 的真正贡献是把"何时调用哪个工具、何时直接出图"的决策收敛到同一策略，避免此前 pipeline 中推理与生图割裂的问题；RAD-GRPO 用互补意图与质量双奖励，是在 Agent RL 中处理多模态目标的可行工程方案。

Ego2Robot：把第一人称人类操作视频转成1.85万小时机器人训练数据

论文指出，学习可泛化的机器人操作策略需要大规模且多样的示范数据，第一人称人类操作视频具备丰富的场景与任务多样性，但此前重定向与渲染方法在单任务小规模上有效，对视觉-语言-动作模型大规模预训练的收益尚不明确。Ego2Robot 给出一条可扩展流水线，通过动作重定向、机械臂视觉合成与多级质量筛选，将第一人称人类操作视频转为机器人训练数据，同时支持精选数据集与 in-the-wild 视频。流水线产出 18,561 小时、覆盖 15 种机器人形态的机器人训练数据，作者称其为迄今最大的 ego-to-robot 数据集。

Insight by AI 把人类视频"翻译"给机器人并非新点，但 Ego2Robot 的关键在于把数据规模推进到万小时级与 15 种本体，逼近真正可用于 VLA 预训练的体量；Ego2Robot + 真机数据的联合预训练能跨视觉外观、场景布局、本体形态与任务语义四个轴稳定提升 OOD 泛化。

RRQ：用单份检查点渐进构造多精度 LLM 量化表征

论文指出，大语言模型在不同部署约束下需要在精度、显存与吞吐间灵活权衡，而传统量化方法通常要为每个目标位宽维护一份独立检查点。RRQ 是后训练量化（PTQ）框架，将权重表示为低比特量化基底加上一串量化残差修正，由单份检查点提供多个有效精度。方法以 2 比特 PTQ 或 round-to-nearest（RTN）起点，渐进叠加轻量 2 比特 RTN 残差，依次构造 4、6、8 比特表示，全程无需校准，也无需联合多比特优化。在 Qwen3-8B 配置下，完整的全 RTN 2/4/6/8 比特构建耗时 1,293 秒，比实测 MatGPTQ 构建快 3.3 倍。论文在六款近期 LLM 上的实验显示，6 比特与 8 比特精度具备竞争力，4 比特表现因模型而异；代码将在发表时公开。

Insight by AI RRQ 的实用价值在于把"一份权重、按需解锁更高精度"做成工程可行的方案，单检查点+渐进残差对多 SLA 部署友好；在 4 比特档位的不稳定提示残余误差累积对不同模型敏感性差异显著，需要配合逐模型调优。
