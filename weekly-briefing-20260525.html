五大关键趋势洞察
T01

后训练 Infra 正在成为独立战场

Cursor Composer 2.0/2.5 基于 TB 级开源模型做中训练 + 大规模 RL，在 coding 能力排名领先。OpenAI o3/o4、Claude 的推理能力均来自 RLVR。RLVR 论文已达 290 篇，进入瓶颈诊断阶段，三个突破方向：轨迹发现（Pedagogical RL，较 GRPO 提升 40%+）、参数动力学（EffOPD 即插即用 3 倍加速）、集群调度（PlexRL GPU 成本降低 37.58%）。核心逻辑：从"更多采样"转向"更聪明的采样"。
RLVRPost-TrainingPedagogical RLEffOPDPlexRL

后训练的价值持续被证实

Cursor Composer 2.0 和 2.5 基于 TB 级开源模型（Kimi K2.5）做中训练 + 大规模 RL，在 coding 能力排名上处于领先水平。围绕训练目标和 Fireworks 合作打造了 RL 基础设施，用一个集群运行全部训练，但强化学习中的推理部分在全球各地的小集群之间分布式进行。OpenAI o3/o4、Claude 的推理能力均来自 RLVR（Reinforcement Learning from Verifiable Rewards）。

RL 帮助 Agent 在真实环境中实现自我进化，需要构建新的训练基础设施

Ineffable（AlphaGo 核心团队创业）与 NVIDIA 合作共建大规模 RL 训练基础设施。与预训练使用固定数据集不同，RL 工作负载实时生成数据，形成"行动→观测→评分→更新"的紧密循环。

RL 基础设施天然比预训练更复杂：既需要数万块 GPU 协同做前向-反向传播，又需要编排大量逼真模拟用户电脑的环境并运行高吞吐推理。RL 环境由三个组件构成——harness（工具执行层）、操作系统（模型交互的真实世界与状态，需虚拟机栈支持高并发 + 弹性扩容 + 快速冷启动）、奖励组件（检查任务是否正确完成）。

RLVR 瓶颈诊断：从"算力不够"转向"算力使用方式"

当前答案越来越偏向算力使用方式：如何找到更好的轨迹、如何更高效地利用轨迹、如何更充分地利用算力。

方向一：轨迹发现 — 瓶颈在"找不到值得学的东西"

Pedagogical RL（MIT/UMD/UND/UCF）核心洞察：现有 on-policy RL（如 GRPO）依赖模型自己偶然碰到成功轨迹来学习。如果模型初始能力不够，根本碰不到成功轨迹，RL 就会停滞——这是探索空间的问题，不是奖励信号的问题。

解法：训练一个拥有特权信息（标准答案）的自教师，要求轨迹正确且每一步对学生模型可学习（spike-aware pedagogy reward），然后用 surprisal-gated imitation 迁移知识。

Llama-3.2-3B AIME 2020-2024 达 22.5%（+40%），用 2-3 倍更少 rollout 达最优

核心结论：从"更多采样"转向"更聪明的采样"。

方向二：参数动力学 — 瓶颈在"更新方向不稳定"

EffOPD（中科大等）确认了 OPD 的效率源于一种"预见"能力——在训练早期就建立起指向最终模型的稳定更新轨迹。

模块分配层面：OPD 识别低边际效用区域，将更新集中在关键推理模块上。更新方向层面：OPD 的主导子空间在训练早期就与最终更新子空间对齐。

EffOPD 即插即用，平均 3 倍加速，无需额外模块或超参数调优

与 Pedagogical RL 互补——一个在数据空间做筛选，一个在参数空间做筛选。

方向三：集群调度 — 瓶颈在 GPU 闲置

PlexRL：面向 RLVR 训练的集群级运行时系统。RLVR 训练的低效是结构性的：长尾 rollout、工具调用阻塞和资源需求不对称在单个任务内无法消除。但不同任务之间的空闲时段呈反相关性，可在集群层面利用。

PlexRL：用户 GPU 小时成本最高降低 37.58%

T02

RSI 叙事增强

Anthropic "When AI builds itself" 披露工程师代码产出提升 8 倍，瓶颈转向人类代码审查。Sakana AI 发布 RSI Lab，六项成果覆盖训练算法发现到自动科学发现。METR 三阶段框架：adequacy / parity / supremacy。RSI 成为新 buzzword，但完全自主自我重写仍缺乏可靠证据。
RSIAnthropicSakana AISelf-Improvement

Anthropic "When AI builds itself"

讨论了 AI 系统参与 AI 研发流程的现实证据。随着更多代码由 AI 推动，组织中的瓶颈开始转移到人类代码审查等环节。同时，AI 带来了大量新想法、工具和模拟，组织吸收能力成为新的限制。

Sakana AI 发布 RSI Lab

明确提出用 AI 重新设计 AI 开发流程。六项成果：训练算法发现、代码自我改写、程序进化、启发式优化、对抗共进化、自动科学发现。共同目标是证明 AI 进步可以通过"思想和搜索效率"复利推进，不只依赖更大模型和更多算力。

社区反馈与关键框架

Hacker News：一方面认可 Sakana 研究创造性，另一方面质疑 RSI 是否退化为"围绕指标优化的 benchmark chasing"。

Reddit：更关注工程效率数字——代码产出提升、Claude 参与代码合并比例、任务时间跨度增长。

METR Ajeya Cotra 将 RSI 划分三阶段：adequacy（无人也能产出研究，预计 1-2 年实现）、parity（AI 等同人类）、supremacy（AI 超越人机协作，parity 后 1 年内可能到来）。

CSET Helen Toner：目前所有所谓的 RSI "只是尽可能多地用 AI 做 AI 研究"，而非经典定义中"不需要人类"的闭环。

核心判断

RSI 已进入早期可观察阶段，但受制于人类审查、评测可靠性和实验资源。当前更准确的表述是 "AI 正在加速 AI 研发流程"，完全自主的模型自我重写仍缺乏可靠证据。

RSI 把 AI 竞争重点从"模型能力有多强"推进到"AI 是否能自动推动下一代 AI 研发"。如果闭环成立，AI 进步速度将不再主要受限于人类研究员，而更多受限于算力、数据和实验基础设施。这也是一个强烈的产业信号：创业公司、知名研究者和 AI 实验室正在把"自动化 AI 研发"包装成下一阶段目标。

为什么中间层值得关注

这些厂商的能力可能生存于模型本身能力提升的缝隙中。国内一般不把搜索这样的中间层当成一条细分赛道（认为 LLM 公司能从模型本身解决这个问题——事实是体验并不好，现在用户绝大多数无用的算力浪费都发生在不能高效且正确地调用 AI 进行搜索），但海外看已经演化出中间层，并且已经盈利。

关键公司

turbopuffer：向量搜索引擎，SPFresh 索引替代 HNSW，存储维度成本优势约 100 倍。跨过 $100 万 ARR 后仅 19 个月突破 $1 亿。

T05

物理 Agent 闭环系统演进

感知、世界预测与动作生成逐步统一到共享模型。NVIDIA Cosmos 3 发布，MoT 架构支持原生动作生成。τ₀-WM 统一视频-动作世界模型。γ-World 多智能体 24 FPS。宇树 WVLA 2.0。趋势不是世界模型替代 VLA，而是VLA 从反应式策略升级为预测式策略。
World ModelVLACosmos 3τ₀-WMγ-World

世界模型和 VLA 的协同

训练层：世界模型帮助 VLA 获得更多动作后果数据。决策层：世界模型帮助 VLA 预演和筛选动作。架构层：世界预测和动作生成逐渐被统一进共享模型。

VLA 解决"根据当前观察应该做什么"，世界模型解决"这样做之后世界会如何变化"。物理智能系统的关键是把动作生成与后果预测连接成闭环——这种协同既可以发生在多个模型之间，也可以被压缩进统一的 world-action model 内部。

趋势不是世界模型替代 VLA，而是：VLA 从反应式策略，逐渐升级为由世界模型支持的预测式策略。

仿真平台与 Foundation Model 的协同

仿真平台/世界模拟器的作用：生成多样化视觉环境用于感知与策略模型训练；根据 Agent 动作实时生成下一观察用于闭环评测；模拟稀有、危险或长尾场景；作为传统物理仿真的视觉生成层。

未来推演：基础模型提出动作 → 世界模型快速想象可能结果 → 物理仿真验证关键动力学和安全约束 → 机器人执行 → 真实数据反哺模型与仿真。

本周关键进展

NVIDIA Cosmos 3（GTC Taipei）：Mixture-of-Transformers 架构，结合视觉推理和多模态生成于单一模型。分为推理块（解析场景）和生成块（生成物理仿真输出），支持原生动作生成（关节角度、夹爪位置等数值数据）。

τ₀-WM：基于共享视频扩散骨干，同时提供视频动作模型和动作条件视频模拟器。训练数据约 27,300 小时真实机器人遥操作和失败轨迹。推理时通过采样 + 重去噪一致性筛选 + 模拟器修正的测试时计算策略选最优动作。

HiF-VLA（西湖大学等，CVPR 2026）：以 motion 为中心实现"边想边做"的世界动作模型。

γ-World（NVIDIA + 清华）：多智能体世界模型。核心创新包括 Simplex Rotary Agent Encoding（无参数 3D RoPE 扩展，置换对称的 Agent 身份编码）和 Sparse Hub Attention（可学习 hub token 中介跨 Agent 通信，注意力从二次降至线性）。可从 2 玩家泛化到 4 玩家交互，无需额外训练。

评测：端到端、长程任务聚焦

ESI-Bench（李飞飞团队）：首个闭合感知-行动回路的具身空间智能评测基准。关键发现：感知不是瓶颈，行动策略才是（"动作盲视"现象）；不完美的 3D 重建比 2D 基线更差；模型存在元认知缺陷——过早以高置信度做出判断，不会寻找反驳证据。

WEM：提出世界-自我解耦的具身世界模型新范式，隐式分离的世界-自我规划器 + 级联并行 MoE 扩散生成器，解决长程任务中导航+操作交替性能退化。

前沿：触觉/力觉模型

新智具身完成近亿元天使轮融资，布局触觉具身智能。

灵巧手挑战：强化学习在仿真中使用低自由度夹爪训练的模型很难兼容高自由度灵巧手；柔性皮肤的仿真环境难以精确模拟柔性、弹性及摩擦力。基于刚性肢体模拟训练的模型迁移到真实机器人差距不大，但高自由度五指型灵巧手很难适配。现在的灵巧操作是真实采集和仿真联合在做。

SECTION 06
观点
01 Sutton 用 26 个字重述苦涩的教训：别迷信人类知识，把赌注押在能随算力扩展的方法上——搜索和学习。26 年了，这个判断一次都没错。
02 从 AlphaGo 到 MuZero，规律重复了四遍：先用人带，再自己学，最后连规则都不需要。人类知识和人类规则只是启动阶段的脚手架，最终都会被拆掉。
03 别再向模型描述世界了，开始构建能体验世界的系统。学习信号比架构更重要——任何在可验证反馈上训练的网络都会产生复利。
04 真正的科学发现只需要三步：产生变化、判断价值、保留有效结果。缺任何一步系统都会崩溃——现在 RLVR 的瓶颈，本质上就是第一步走不通。
05 Sutton 的新论文在说一件很根本的事：主流 AI 把感知当成被动的信息接收，但你感知世界的方式是通过行动——先动手再感受，不是先看清楚再动手。
06 Sutton 也是世界模型的奠基人。Dyna 架构的核心思想就一句话：学习、规划和反应不该是三套独立系统，应该在同一个大脑里闭环运转。
07 Agent 能不能理解用户没说出口的需求？π-Bench 测了个扎心的结果：最强的模型任务完成度 67.6 分，主动性也就 60 分出头。会做事和会主动问，是两种完全不同的能力。
08 用"知识""推理""理解"这些人类认知概念来描述大模型，可能正在系统性地误导我们的判断。我们以为在理解模型，可能只是在用错误的框架自圆其说。
