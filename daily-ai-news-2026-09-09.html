Inception 发布 Mercury 2.5：最强扩散 LLM，1100+ tok/s 且智能较上代提升 40%

Inception 发布 Mercury 2.5，自称市场上最强、据信也是迄今训练过的最大扩散语言模型：智能水平较 Mercury 2 提升 40%，官方称可与 GPT-5.6 Luna（Low）、Gemini 3.5 Flash-Lite、Claude Haiku 4.5 等成本优化的前沿模型对标；在广泛可得的 NVIDIA GPU 上跑出 1107 tok/s，支持 260K 上下文，定价每百万输入 0.20 美元、输出 0.75 美元。公司称自 Mercury 2 发布以来用量增长超一个数量级，已通过 API、OpenRouter 与 Baseten 提供。

Insight by AI 扩散 LLM 路线首次在"智能-速度"两轴上同时摸到成本优化前沿模型的门槛；若 40% 的提升在第三方基准站得住，Mercury 将把"亚秒级首 token + 千级吞吐"从 demo 变成生产可选。

Cohere 发布基于 decode megakernel 的开源推理系统

Cohere 发布技术深度文章并开源其面向 North Mini Code 的 decode megakernel 服务引擎：把整个解码前向压进单个 kernel，消除小 batch 下逐 kernel 启动的等待开销。North Mini Code 为 30B 总参、3.3B 激活的模型，BF16 下每步解码需从 HBM 流过约 6.6GB 权重，H100 3.35TB/s 带宽对应理论上限约 470 tok/s；实测在单张 H100 上端到端比 vLLM 快 1.25–1.41 倍（官方称特定配置最高 1.58 倍），代码已在 GitHub 开源。

Insight by AI 把推理内核从通用调度框架拆出、做成单内核，意味着 Cohere 把推理层的差异化押在底层 kernel 的极致优化上；这条路线对自研模型公司门槛不低，但单位硬件吞吐的提升直接转化为服务成本优势。

Google DeepMind 发布 AlphaGenome Atlas：预测人类基因组全部 90 亿个单字母变异的影响

DeepMind 推出 AlphaGenome Atlas，一个 AI 驱动的可搜索数据库，对人类基因组中全部约 90 亿个可能的单字母 DNA 变异（SNV）逐一生成分子层面的影响预测，相当于给基因组装上一张"变异影响地图"。研究者可按基因、变异类型或预测效应检索，用于理解致病机理、 prioritise 实验验证对象等场景。该数据库建立在 AlphaGenome 模型对 DNA 序列到分子表型的预测能力之上。

Insight by AI 把"每个可能变异都先算一遍影响"做成公开可搜索的基础设施，意味着变异解读从"逐个查询模型"变成"查地图"；对罕见病与复杂疾病的变异优先级排序是直接受益场景，但也把"预测即证据"的验证责任压给了下游实验。

论文提出 Dr. Claw：以人类决策为锚点的 AI 研究工作空间

论文介绍 Dr. Claw，一个围绕既有命令行编程智能体（Claude Code、Gemini CLI 等）构建的开源工作空间。它通过持久化状态对象、可复用的技能库与多执行器协调，把规划、执行与写作串成一条可追溯、可回滚的链路，并以人在回路的方式保留关键决策。论文以三视图交互场景和故障恢复演练展示其流程，并在固定底层执行器的前提下对比裸命令行智能体。仓库以 AGPL-3.0 发布，含 GPL-3.0 上游组件。

Insight by AI 研究流程最大的可信度短板不在生成，而在决策可审计性；Dr. Claw 把可审计性外化为状态对象与技能库，是把 IDE 经验迁移到 AI 协作的关键一步。
HuggingFace Daily Papers / arXiv

论文提出扩散增强 LLM：以扩散权重并行采样，无损加速自回归生成

针对 LLM 自回归结构必须逐 token 串行生成的瓶颈，论文提出 diffusion-augmented LLM：保持自回归模型定义的分布不变，把参数拆成两组——用标准 next-token prediction 训练的 AR 权重，加上可并行生成多个 token 的轻量扩散权重；扩散权重通过一个简单的 Diffusion Distillation 阶段习得，对现有 LLM 训练管线几乎零侵入。配套的 Ψ-Spec 采样器家族可实现在生成分布不变前提下的无损加速（摘要含无损/有损模式的权衡分析）。

Insight by AI "AR 定义分布 + 扩散并行采样"的解耦设计，让扩散加速不必重训基座模型就能叠加到现有 LLM 上；与 Inception 的原生扩散 LLM 路线形成"改造存量 vs 训练增量"的互补。

FlowBalance：用验证器校准的自我引导，替代脆弱的自提升内循环

推理模型从自身 on-policy 经验中自我提升的内循环存在两难：终局验证器监督可靠但稀疏，同模型的密集引导可能强化错误自信或让解法过度集中。论文提出 FlowBalance：对完整响应学习一个归一化分布，用策略的训练时冻结视图在特权上下文下产生 token 级 log-probability 增益，聚合为轨迹级自我引导分数，再与验证器导出的组优势校准——正优势轨迹保留引导、负优势轨迹反转引导，从而只放大"被验证认可"的自我信号。

Insight by AI 把"自我引导"从无条件信任变成按验证器优势方向调制的信号，是对 self-improvement 最常见失败模式（错误自信的复利）的直接工程解，思路可移植到任何带验证器的 RLVR 管线。

论文以博弈论框架分析多智能体 LLM 协调与反思机制

论文把多智能体 LLM 系统中的编排者—工作者交互建模为一个双层协调博弈，并在有界耦合条件下证明工作者局部更新博弈近似势博弈、均衡松弛由任务分解质量控制。论文进一步把反思视作语义记忆状态上的随机游走，针对自由形式反思给出有限时间上界、最坏情形紧界与持续伤害条件下的正下界，并证明仅观察生成文本的门控无法在文本不可区分环境上一致改进。论文提出 Stochastic Reflective Memory Ascent（SRMA），仅在环境评估风险严格下降时接受候选记忆，并在不同条件下给出几何或多项式收敛保证。基于 Kimi 的系统在 500 个 SWE-bench 实例上解决率达到 72.2%，高于 70.8% 的 mini-SWE-agent 参考基线。

Insight by AI 反思机制长期被视为经验调参对象，这篇工作把多智能体协调与记忆更新纳入博弈论与信息论框架，SRMA 为反思提供了带收敛保证的工程基线。

SemiAnalysis 指控 Gemini 3.8 Flash 与 Muse Spark 1.3 "刷榜"，公开基准的宿命论

SemiAnalysis 发推称 Gemini 3.8 Flash 与 Muse Spark 1.3 是"迄今最明显的 benchmaxxed 模型"：两者在 Terminal Bench 2.1 上与 GPT-6、Fable 5.1 相当，但在刚发布两周的 Terminal Bench 4.0 上表现显著更差。其解释是：TB 2.1 任务全部公开，Meta 和 Google 不会直接拿任务训练，但会从 RL 环境创业公司购买高度模仿 TB 2.1 任务的数据，净效果等同直接训练；通常 TB 2.1 的提升应泛化到其他 agent 任务，但这两个模型连 TB 4.0 都不泛化。其判断"这是一切优秀公开基准的宿命——TB 4.0 现在有用只因发布才两周"，并举 Gemini 3.8 Flash 在 DeepSWE 上的表现为例（暗示 Datacurve 靠出售 DeepSWE 形状任务赚了大钱），最后呼吁更多高质量私有基准。

Insight by AI 这条推文把"公开基准失效"的机制讲透了：污染不发生在基准本身，而发生在"形状足够接近的训练数据市场"；对评测方的启示是私有基准+轮换任务的经济学价值正在上升，对模型买家的启示是选型应优先看新发布基准上的成绩。

OpenAI 公布千禧年数学难题 Navier-Stokes 完整证明：下一代模型驱动的 Agent 群体消耗 3 千亿 token

OpenAI 公布针对千禧年数学难题 Navier-Stokes 存在性与光滑性的完整证明，称由一组 Agent 群体使用一款显著强于 GPT-6 Astra 的下一代模型完成；这场为期一周的攻坚消耗约 3000 亿输出 token，按 API 牌价折合约 2250 万美元算力，该模型近期还攻克了多个其他未解问题。事件另一面：NYU 数学教授 Tristan Buckmaster 同日宣布与 Anthropic 数学家 Levent Alpöge 合作（借助 Codex 与 Claude）的三个证明及针对同一问题的初步结果，并在声明中指出 OpenAI 的平行工作在其成果公开发表前即已建立在他们的工作之上，引发学术优先权争议；OpenAI 方面称两个证明相互独立。

Insight by AI 一周 3000 亿 token 的"燃烧式研究"标志着 AI 数学研究进入重投入时代，而"Buckmaster→OpenAI"的优先权之争比证明本身更值得行业警惕——当模型可以实时消化预印本与私下交流的思路，学术界的首发保护机制近乎失效。

vLLM 推出 Hybrid HiSparse 内存分层，让 GLM 5.3 在 8×H200 节点上跑满 100 万上下文

vLLM 团队发布 GLM 5.3 优化系列第一篇，介绍将 HiSparse 作为受压驱动的内存层与 Hybrid Memory Allocator 和 KV offloading 组合，在 GLM 5.3 请求 KV 超出显存时仍可继续解码，从而维持高并发。文章指出，在单节点 8×H200 的紧内存配置下，Hybrid HiSparse 使 GLM 5.3 首次得以在该硬件上跑满 100 万上下文长度，并在不同上下文长度下显著提升并发。

Insight by AI HiSparse 把稀疏性从权重扩展到 KV 生命周期管理，让单节点能承载百万级上下文的高并发 Agent 推理，意味着长上下文服务的边际硬件成本有望继续下降。
