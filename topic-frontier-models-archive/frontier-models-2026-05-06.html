ARC-AGI-3 深度分析（5/3）——GPT-5.5 和 Opus 4.7 的推理缺陷被解剖
置信度：高

ARC Prize Foundation 分析了 160 次 GPT-5.5 和 Opus 4.7 在 ARC-AGI-3 上的交互运行，揭示 三种系统性推理错误： | 模型 | ARC-AGI-3 分数 | 人类 | 差距 | |------|---------------|------|------| | GPT-5.5 | 0.43% | 100% | 233x | | Claude Opus 4.7 | 0.18% | 100% | 556x | | Gemini 3.1 Pro | 0.37% | 100% | 270x | 三种系统性错误： 1. 错误模式强加：将熟悉模式强行套用到不熟悉任务上（Opus） 2. 假设放弃过早：形成正确假设后过早放弃（GPT-5.5） 3. 探索不足：系统性地未能充分探索环境以形成正确假设 关键解读： - 这不是"分数低"的问题，而是"推理模式根本不同"：当前模型的所有推理都建立在"压缩已知模式"上，ARC-AGI-3 要求的是"在无指令环境中从零发现规律" - Opus vs GPT-5.5：两种截然不同的失败模式，暗示当前 scaling 路线在"探索式推理"上或遇到瓶颈 - 与上期信号呼应：上期判断"Terminal-Bench 正在取代 SWE-bench 成为 Agent 时代核心 benchmark"，ARC-AGI-3 数据显示"Agent 能力与通用推理能力存在显著分化"——0.43%/0.18% vs 人类 100% 的差距暗示两者可能并非同一维度

IKP 论文（5/1）——反推闭源模型参数量，方法论争议中核心结论成立
置信度：中

Pine AI 首席科学家 Bojie Li 单人论文，提出 Incompressible Knowledge Probes（IKP）：利用信息论下界——存储 F 个事实至少需要 F/(bits per parameter) 个权重——通过 1,400 道跨 7 个冷僻度等级的事实问答测量模型知识容量，反推参数量。 原论文声称： 89 个开源模型校准 R²=0.917，闭源估算：GPT-5.5 ~9.7T、Claude Opus 4.6 ~5.3T、Claude Opus 4.7 ~4T。 LessWrong 独立复现（5/1，两位研究者）发现： - 核心思路成立：事实记忆与参数量的对数线性关系在所有子集（≥0.5B、≥10B、dense-only、MoE-only）上斜率稳定在 ~0.15 - Densing Law 确实不成立：时间系数 γ 在所有回归变体中均接近零，scaling 远未饱和这一结论经受住了所有压力测试 - MoE 总参数 > 活跃参数：600B 总参 MoE 的知识容量接近 600B dense，而非 37B active dense - 但具体数字不可靠：代码中存在 per-tier flooring（论文声称未做）、~10% 高难度题目有歧义或答案错误。 - 结论：具体万亿级参数估算"对方法论选择极度敏感"，不应作为可靠数字引用；但"scaling 远未饱和"的核心结论成立 关键解读： - "Scaling 未死"结论可信：三项核心发现（对数线性关系、Densing Law 不成立、MoE 总参数预测知识）均通过独立复现验证 - 具体参数量数字需谨慎：GPT-5.5 可能是 1.5T-9.7T 之间的某个值，置信区间极宽。不应引用 "~9T" 作为确定数字 - 方法论贡献 > 具体数字：IKP 作为"通过知识容量反推规模"的思路是真正的贡献，但当前数据集质量（歧义题、错误答案）限制了精度

置信度：高

本周 CAISI 连续发布两个重大动作，正在从"审查机构"变为"竞争格局的定义者"。 动作一（5/5）：前置安全审查签约 Commerce Department 下属 CAISI 与 Google DeepMind、Microsoft、xAI 签署协议，在模型公开发布前进行国家安全评估。此前 Biden 时代已与 OpenAI、Anthropic 签署类似协议。 动作二（5/1）：DeepSeek V4-Pro 官方评估 CAISI 首次对中国前沿模型发布系统性评估。核心结论： | 指标 | CAISI 评估结果 | |------|---------------| | DeepSeek V4-Pro 总分 | ~800 分 | | GPT-5.5 总分 | >1200 分 | | GPT-5.4 / Opus 4.6 | >1000 分 | | 差距判定 | V4 ≈ 8 个月前的 GPT-5 | | 成本优势 | vs GPT-5.4 mini，7 项中 5 项更便宜（高 41%-53%） | | 定性 | "CAISI 评估过的最强大中国 AI 模型" | CAISI 同时发布中美模型能力随时间推移的对比图，暗示差距正在扩大。 方法论争议： - The Decoder 质疑：CAISI 的评估"很可能带有自身的政治目的"，作为美国商务部下属机构，其评估立场天然偏向美国 - Artificial Analysis 反证：独立分析机构 Artificial Analysis 的评估认为 DeepSeek 与 OpenAI 的差距实际上正在缩小，与 CAISI 结论相反 - DeepSeek 自评 vs CAISI 评估：DeepSeek 官方声称 V4-Pro 与 GPT-5.4 相当，CAISI 将其下修至 GPT-5 水平（8 个月前） - 外交关系委员会参照：美国外交关系委员会 3 位高级研究员此前评估差距约 7 个月，与 CAISI 的 8 个月基本一致 - 成本维度被承认：即使 CAISI 也确认 DeepSeek V4 在成本效率上领先——这是美国政府机构首次正式承认中国 AI 的成本优势 关键解读： - 这是美国政府首次对中美 AI 差距给出量化定义：800 vs 1200+ 的评分体系将成为政策制定（出口管制、投资限制）的"数据基础"。但评估机构本身的立场需要被标注 - 安全审查 + 竞争评估 = 监管双轨制：CAISI 同时做"安全门控"（前置审查）和"竞争定位"（差距评估），前者约束盟友，后者定义对手 - OpenAI 和 Anthropic 未在本次安全审查签约名单中：可能因为已有旧协议在运行；Google/xAI/MS 被纳入意味着审查范围从"前沿实验室"扩展到"平台型公司" - 成本优势是更客观的信号：无论评估方法论如何争议，7 项中 5 项更便宜的事实来自定价数据，不依赖评估框架 - 对发布节奏的影响：前置审查可能增加新模型发布延迟，尤其影响 Google（已 76 天未发旗舰）和 xAI（激进发布节奏）

非共识判断

  1. "Benchmark 饱和"的表述可能掩盖了真实结构：GPQA 饱和不是因为模型接近"智能上限"，而是因为它测的是"压缩已知知识"——这个任务对当前模型基本完成了。ARC-AGI-3 近乎零分也不是因为模型"不够聪明"，而是因为它测的是"在无指令环境中从零发现规律"。用"饱和"描述这两类现象可能掩盖关键差异：在"探索式推理"这个维度上，scaling 的有效性尚未得到验证。

  2. ARC-AGI-3 的两种失败模式指向不同的推理缺陷，而非同一个问题：Opus 4.7 的问题是过度压缩（把不熟悉的任务强行塞进熟悉模式），GPT-5.5 的问题是不压缩（无法收敛到稳定假设）。Mythos 如果在 ARC-AGI-3 上同样接近零（几乎可以确定），暗示当前 LLM 范式在"探索式推理"上可能存在结构性限制——修复是否需要新的训练目标或架构，尚未有定论。

  3. 开发者生态出现"模型能力 ≠ 产品体验"的第一次真实分叉：OpenAI 解除 Azure 独占（模型可上 AWS Bedrock / Google TPU）降低了接入门槛，但 @theo 的实测发现"GPT-5.5 更聪明，但 Opus 的意图理解和 taste 更好"，且 GPT-5.5 放进 Claude Code harness 后在 PostTrainBench 上未能打赢 Opus。这可能部分来自 harness 优势，也可能部分来自 Opus 在 agent 场景上的特定能力，两者难以拆分——但无论归因为何，对开发者来说结果相同：最强模型 ≠ 最佳体验。Copilot 6/1 转按用量计费后，@theo 展示了 $221/15 messages 的真实账单。三个变化同时发生（多云分发 + 用量计费 + 真实账单冲击），第一次提供了市场价格弹性的真实数据——开发者在"最强模型""最佳体验""最具性价比"之间的三角选择，下月就能看到。

  4. Sakana Fugu 的 SWE-Pro 54.2% 是本周最重要的未验证信号：如果第三方验证，意味着"训练更好的调度器"在编程任务上可以替代"训练更强的模型"。但目前只有 Sakana 自述数据，GPQA Diamond 和 LiveCodeBench 同样缺乏第三方验证——这两条线都需要等，不应基于未验证数据做结构性判断。

  5. Grok 4.3 的低价或许是 L1 结构优势 + accuracy 取舍，不是模型效率突破：拆解 $1.25/$2.50 的定价——xAI 自有 Colossus 集群（100K+ H100）不付云厂商溢价（L1 成本优势）；non-hallucination -8 分、Vending-Bench 2 个重大回退说明低价伴随 accuracy 代价（具体是蒸馏/量化/对齐取舍，原因未公开）。是否低于成本线取决于 xAI 未公开的算力利用率——如果 Colossus 利用率不满，边际成本可能确实很低；如果接近满载，则大概率在亏损抢开发者生态。护城河不在模型层（L2），在算力基础设施（L1）和定价策略——"性价比"需要更精细的定义。

  6. 在 Agent 场景下，系统层（L3）的边际收益正在放大：三条独立证据线均来自 Terminal-Bench（agent 完成终端任务）——AHE 论文通过自进化 harness 把 Terminal-Bench 从 69.7% 提到 77.0%（+7.3pp），超 Codex-CLI 71.9%，且可跨模型迁移；Mason Drxy 仅通过 prompt 调优把 gpt-5.2-codex Terminal-Bench 从 52.8% 提到 66.5%（+13.7pp）；Sakana Fugu 7B 编排器超越池中所有单模型。但需要注意：目前所有证据集中在 Agent/编程这一个场景，Terminal-Bench 恰好是 harness 影响最大的场景——换成数学推理（FrontierMath）或知识问答（GPQA），harness 的边际贡献可能完全不同。从单场景推"L2→L3 竞争焦点全局迁移"跨度太大，更审慎的说法是：在 Agent 场景，harness engineering 可能比模型选择更能决定效果上限。这与 SemiAnalysis 观察到的利润向模型层集中是不同维度的现象——SemiAnalysis 说的是产业链利润分配（谁赚更多钱），这里说的是特定场景下的竞争要素权重（什么决定产品效果），两者不宜直接串联。
