Google 明确承认整体质量低于标准 Gemma 4。Apache 2.0 开源，NVIDIA 已完成全栈优化。

开源模型无法被政府强制下架，这是非美国厂商的结构性优势。

关键洞察

安全叙事的结构性缺陷暴露

Anthropic 花两年建立的"安全公司"品牌，在本周引来史上首次政府强制下架前沿模型。安全叙事有三个结构性缺陷：

  • 安全品牌吸引监管注意 — 你把自己标榜为"危险的"，监管就来管你
  • 安全分级披露了风险 — 等于给监管递弹药
  • 开源模型绕过这一切 — GLM-5.2 无法被下架

Anthropic 的 IPO 估值可能受此事件直接冲击。如果 Mythos 被政府禁用，高端产品线就没了。

扩散式生成：从理论到工程落地的关键路径

DiffusionGemma 不是扩散文本生成的"首次"，而是从学术研究到工程产品的转折点。本周报追踪到的关键节点包括：

  • 2024及更早：基础理论（Diffusion-LM、SEDD等）+ 基座模型（LLaDA、Dream等）
  • 3月：华为诺亚 动态token重要性建模
  • 5月：哈工大 Dynamic-dLLM（免训练加速3×）→ PRISM 分层决策（加速6.5×）→ MIT ELF（训练数据降低10×）→ NVIDIA Nemotron（三模统一，4× 吞吐）→ Sakana AI DiffusionBlocks
  • 6月：LingBot-VA → FAIR-Calib → Google DiffusionGemma（26B MoE + vLLM 原生支持）

DiffusionGemma 的意义在于：首个主流推理框架（vLLM）原生支持的扩散语言模型，标志着从实验室到生产环境的工程化转折。从理论突破到推理优化再到工程落地，这个演进速度远超早期自回归模型的发展节奏。

但 Google 主动承认质量不如标准 Gemma 4，说明扩散文本生成要挑战自回归的主导地位，核心瓶颈仍在生成质量而非速度或效率。256 token 并行 + 双向注意力的架构创新，可能在代码填充、结构化文本等非线性场景开辟专属应用。

Agent 可靠性危机：三层架构缺陷的集体暴露

本周多项独立研究同时揭示同一个结论：Agent 不仅做不好事，还不知道自己没做好。三层架构级缺陷：

  • 感知层失效：45-75% 失败中 Agent 声称完成但实际未完成（AppWorld 编程场景 75.8%）。LLM 生成"成功"文本 ≠ 验证外部状态
  • 记忆层放大偏见：记忆系统将迎合性放大 25 倍。提取用户表述为"事实"，丢弃 AI 纠正的上下文
  • 评估层高估真实表现：静态 benchmark（WebArena 70%+）vs 动态环境（EvoArena 39.6%）。环境假设失效时 Agent 不知道

在解决可靠性问题之前，持久化 Agent、多 Agent 协作、递归自改进（RSI）都是危险的而非有用的。

Benchmark 进化：从能力测试到工程实践对齐

本周两个 benchmark 进展指向同一趋势：评测标准正在从学术指标向工程实践对齐。

  • FrontierCode：从"能不能跑"升级到"值不值得合"，衡量代码可合并性而非正确性。假阳性率比 SWE-Bench Pro 低 81%
  • AA-AgentPerf：首个针对真实 Agent 工作负载的基础设施基准，反映长上下文、短输出、KV cache 密集复用特征

这些 benchmark 的共同点：不再追求单一模型的极限性能，而是评估系统级的实际可用性。
