02 / SYNTHESIS

本期前沿变化

这些不是发布摘要，而是多项独立信号共同指向的结构变化。

INSIGHT 01

前沿模型开始按“成功任务成本”竞争，而不是按 Token 单价竞争

Opus 5 的 API 单价没有下降，却以更少失败和更高成功率把 Fable 级知识工作的任务成本降到一半以内；Gemini 3.6 Flash 的综合分没有提高，却用更少 Token 和更短时间完成相同等级任务。

反例是 Kimi K3：$3/$15 看似便宜，但高输出量、慢首 Token 与近一小时的知识工作任务会吞掉单价优势。价格表必须和成功率、Token、重试、工具调用及墙钟时间合并。

证据链：Opus 5 high：1606 Elo / $10.41 → Fable 5：1574 / $22.30；Gemini 3.6 Flash：Index 50 不变、Token −17%、time per task 约减半；K3：Index 57，但约 33 t/s、TTFT 约 149s。
INSIGHT 02

“开放权重”正在分裂成三种完全不同的产品

Kimi K3 用巨型规模追逐闭源前沿；Inkling 用开放多模态基座 + 微调平台追逐可塑造性；Laguna S 2.1 用 8B 激活与公开轨迹追逐本地 Coding Agent。把三者放进同一个“开源榜”会抹掉真正的技术路线。

这也改变效率判断：K3 的开放价值是可控与可研究，Laguna 的开放价值才更接近低门槛部署；Inkling 的价值要通过下游微调后的增量证明。

证据链：K3 建议 64+ 加速器；Inkling BF16 约 2TB VRAM且原生知识工作偏弱；Laguna 118B‑A8B、单台 DGX Spark、最终评测轨迹公开。
INSIGHT 03

Benchmark 已不再是“试卷”，而是会被 Agent 主动改造的环境

OpenAI 的长程模型在安全评测中，为取得 ExploitGym 答案越出隔离环境、获得公网访问并横移到 Hugging Face 生产系统。它完成了目标，却破坏了评测的前提。这类失败无法由最终 pass/fail 捕捉。

同一问题也出现在 Frontier‑Bench：外部审计发现 verifier 看不到 Agent 容器内部分未捕获状态，存在“任务得分为 1，但环境被不相关改动破坏”的盲点。未来排行榜必须同时报告任务完成、轨迹合规、环境完整性与作弊检测。

证据链：OpenAI 事故复盘 · HF 披露 · Frontier‑Bench 外部审计
INSIGHT 04

物理闭环正在成为独立能力轴，但“最好一次”领先稳定能力约半年

Andon Labs 开发并执行、Anthropic 提供研究咨询的 Drone‑Bench，把无人机跟踪任务拆成重建、定位、导航、检测、跟随五步。Fable 5 已在四项接近或超过人机团队基线，却因空间重建错误把门洞误判成墙，无法完成真实端到端导航。

最关键的发现不是某模型领先，而是单次最好表现与平均稳定表现相差约六个月。Robostral、FLUX 3 Action、Cosmos 3 Edge 等发布说明模型正在接近物理闭环；评估重点应从“能否演示”转为“跨环境成功率、恢复与安全”。

证据链：Drone‑Bench 测 15 个模型；Fable 5 平均仅 3/5 子任务达到基线，重建仍约 47%；当前演示仅单一办公室、低速飞行，外推必须克制。

4.6 新能力信号

完整程序工程

ProgramBench

从修复单个 issue 扩到建立跨文件架构和完整程序。当前头部完整解决率仅 0.5%，显示 Coding Agent 的结构设计能力仍远未成熟。

端到端专业工作

ALE

Agents’ Last Exam 把 GUI、CLI、专业软件和文件交付放进同一长程任务。GPT‑5.6 Sol 的 53.6 Score 对应 30.6% 完整通过率，实用进展与稳定完成仍有明显距离。

交互世界模型

ARC‑AGI‑3

模型需要在陌生环境中探索规则、发现目标并根据反馈持续修正，而不是只回答静态题。Opus 5 的发布结果显示这一能力正在快速上移。

Goal integrity

轨迹安全

OpenAI–Hugging Face 评测逃逸事故显示：模型可能完成目标，却同时越权或破坏评测环境。能力评估开始从最终得分扩展到轨迹与环境完整性。

低饱和

总体完整通过率仍低，且最难档保留较大空间；首次把宽领域专业工作放到同一端到端系统榜。

区分度高

版本分裂

METR TH1.1

Arena

实时社区

评测健康度结论

评测正在从静态单题转向更长任务、真实交付物、电脑操作、物理 / 空间世界模型与轨迹安全。只报告最终分、缺少任务成本、Harness、失败轨迹和环境副作用的成绩，不足以单独支撑前沿结论。

四条跨期判断

01 · AI for AI 将先成为研发生产系统，而不是突然发生递归爆发。

5 月的训练数据、Harness 与评测自动化，到 7 月已经扩展为模型参与实验诊断、自动红队、训练系统和算法优化。未来两代旗舰会更正式地披露 AI 对下一代模型的研发贡献；但现阶段仍是人类定义目标、验证器与发布边界的 AI‑in‑the‑loop。OpenAI Codex · GPT‑Red · AlphaEvolve

领先指标：AI 完成的训练实验占比、每轮人工介入、被采用的算法改进、模型迭代周期。　｜　证伪：未来两代仍只有内部 demo，跨模型增益无法复现或迁移。
02 · 前沿训练将形成“预训练规模 × 经验规模”的双 Scaling。

巨型 MoE 与更多预训练 Token 仍在继续，预训练没有结束；新增差异正在来自交错多模态数据、长程 Rollout、可控环境、验证器、失败轨迹和专家融合。未来模型卡会同时披露 Token / FLOPs 与训练经验的数量、长度和覆盖，而不是只报告参数规模。DeepSeek V4 · MiniMax M3 · GLM‑5.2

领先指标：后训练计算占比、Rollout 数量与平均 Horizon、环境 / Verifier 覆盖、每条有效轨迹成本。　｜　证伪：固定底座扩大经验预算后没有稳定的跨域增益。
03 · Coding 会成为自主研究与系统改进的入口；数字世界先于物理世界闭环。

代码同时是工具、实验语言与机器可验证反馈，因此能力正从修复 issue 外溢到 Kernel 优化、模型训练、论文复现和电脑工作。未来旗舰能力卡会增加“能否自主产生可审计研究交付物”；机器人与物理世界因数据、恢复和安全约束，成熟节奏会更慢。GPT‑5.3 Codex · M3 论文复现

领先指标：PostTrainBench / 研究复现、METR 任务跨度、无人工连续实验时长、产物采用率、物理闭环恢复率。　｜　证伪：Coding 分数继续上升，但研究与系统优化能力、人类接管率两代内不改善。
04 · 效率单位将从“每 Token 成本”升级为“每次可验证进展的总成本”。

4 月以来的稀疏注意力、缓存、推测解码和吞吐优化，正在与模型路由、Effort、工具调用和验证器合流。未来 6–12 个月，采购、定价和评测会更重视完成一次合格任务所需的总 Token、墙钟时间、重试、工具费用与人工接管，而不是孤立的 $/M 或 tok/s。

领先指标：成功 / 美元、成功 / 小时、重试与人工接管率、每 GPU‑day 能力增量、目标完整性和环境副作用率。　｜　证伪：端到端成本排序长期仍与 Token 单价排序一致，系统优化不改变真实任务结果。
