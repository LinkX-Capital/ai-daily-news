阿里 Qwen3.8-27B 端侧模型发布数日下载量破百万

阿里发布了一款可在用户个人电脑上运行的小尺寸 AI 模型 Qwen3.8-27B，参数量为 270 亿，支持文本、图像与视频提示词输入，并可免费下载。阿里表示，该模型在发布后短短几天内下载量已超过 100 万次，是其增长最快的模型之一。

Insight by AI 对参数量 270 亿、且支持多模态输入的模型做“个人电脑可跑”的定位，意味着开源模型竞争已从云端跑分转向端侧可用性，端侧部署体验与硬件适配会成为下一阶段分化的关键。

研究关注

StateM 以 95.3% 原始准确率刷新 Terminal-Bench 2 纪录

StateM 是一种面向 Agent 的运行时，通过持久化状态、阶段本地上下文、检查点迁移、可恢复 Runbook 与版本化的流程实践来组织执行流程。在 Terminal-Bench 2.1 上，StateM 将 GPT-5.5 xhigh 从 83.1% 提升至 92.1%，超过 GPT-5.6 Sol Ultra 的 91.9%；同一 Runbook 不做改动迁移到 GPT-5.6 后，使用 GPT-5.6 Sol xhigh 可在 445 次试验中达到 95.3% 原始准确率，并在全部 89 个任务上至少成功一次。冻结配置还将 GPT-5.6 Luna 从 76.7% 提升到 85.4%，高于 84.9% 的 Sol xhigh 参考值。同样的运行时、Runbook 结构与黄金规则下，DeepSeek-V4 Flash 在标准超时下由 82.7% 提升到 88.1%，88 题公共核心上达到 89.1%；总花费 52.22 美元，对应 GPT 参考实现 574.68 美元、StateM 最终分数 API 用量约 15 美元。代码已在 github.com/henryqin1997/statem 开源。

Insight by AI 把工程化 Runtime 与可版本化的 Runbook 作为与模型权重并列的一阶对象，StateM 用“不到 38 美元的适配”在多款模型上稳定拉开 4–9 个百分点，说明在长时程任务上，外层执行结构本身就是可独立优化的杠杆。

DumpsterCluster 用二手 GPU 拼出 128 卡集群跑 LLaMA-70B 推理

论文提出并实际搭建了一台由 128 块二手 GPU 组成的 DumpsterCluster，并以这套 V100 集群为平台研究退役加速器能否用于现代大模型推理。论文同时给出可核验的成本测算：在当前市场价位下，DumpsterCluster 整机的价格约为 2.2 万美元，而一台 8 卡 B200 系统约为 60 万美元。论文强调，其 V100 集群凭借流水线并行优化后，LLaMA-70B 吞吐量达到了具备生产可行性的水平。

Insight by AI 退役 GPU 复用必须与电力价格和电网碳强度耦合，不能单按硬件价格判断 TCO；只有同时落在低电费与低碳排放区的部署，才能把硬件折价真正转化为可持续的算力增量。

Prior Labs 开源 RelArena-α、TabPFN-Rel 与 RPI，主打关系学习可复现基准

Prior Labs 在 Hugging Face Daily Papers 发布第一份关系学习方向的开源材料，公开三件套 RelArena-α、TabPFN-Rel 与 RPI，目前以 α 版本面向研究者和早期实践者。RelArena-α 在 RelBench v1 之上统一了数据加载、评估协议、调参规范以及自定义调参支持，并借鉴 TabArena 设计，目标是为不同方法提供可复现的横向比较。TabPFN-Rel 是面向 TabPFN-3 的专用关系学习 harness，目前在 RelArena-α 榜单上排名第一，并作为基线展示了把关系数据展平为单张表仍可与专用架构匹敌。

Insight by AI 关系学习的卡点和 LLM、CV 早期类似——不是缺模型，而是缺统一基准；RelArena-α 抢在社区收敛之前把评测框架立起来，有助于把后续工作逼到可复现的同一坐标系内比较。
HuggingFace Daily Papers

MR-Traj 提出多分辨率扩散框架，可为城市系统合成大规模轨迹数据

论文针对公开大规模轨迹数据受隐私限制、合成方法又长期偏重全局分布相似度的问题，提出多分辨率扩散框架 MR-Traj，用于城市级轨迹生成。MR-Traj 把轨迹拆解为粗粒度里程碑与细粒度分段，从而显式建模跨时空分辨率的复杂依赖。在公开轨迹数据集上的实验显示，MR-Traj 在全局分布相似度上与现有 SOTA 持平，但在细粒度移动模式与下游城市交通任务上稳定优于既有方法。

Insight by AI MR-Traj 在多分辨率粒度上同时建模与注入随机性，把下游任务可用性和去链路化隐私风险一同端到端处理，这是合成轨迹从“像数据”走向“可分析、能发布”的关键升级。
arXiv cs.LG

DeMTS 将扩散语言模型的去噪轨迹建模为多元时间序列，用于幻觉检测

论文针对扩散语言模型（D-LLM）同样存在幻觉、且现有检测方法只沿时间或 token 单维压缩去噪轨迹的问题，提出 DeMTS 框架。该方法把去噪轨迹重构成基于可学习潜变量的多元时间序列，借助轨迹保留的 token-to-variable 分配模块把 token 信号转为稳定潜变量，再通过动态多元时间建模把跨变量依赖与时间编码逐步融合，用于幻觉预测。论文报告在两类 D-LLM 主干与三个基准上的实验显示，DeMTS 在检测精度、鲁棒性、效率与跨任务迁移能力上均优于既有方法。

Insight by AI 把 2D 去噪轨迹升格为多元时间序列后，幻觉相关的“收敛不一致”和“跨 token 故障传播”才被显式建模，这意味着 D-LLM 的可信度评估正补齐和自回归 LLM 同级别的诊断粒度。
