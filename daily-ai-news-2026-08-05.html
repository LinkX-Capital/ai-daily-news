HP、华硕、宏碁开始在PC中采用中国CXMT的少量内存芯片

据日经亚洲报道,包括HP、华硕和宏碁在内的主要PC制造商已开始在其产品中使用中国内存厂商长鑫存储(CXMT)的小批量芯片。在全球科技行业因AI基础设施需求激增而面临严峻的内存芯片短缺背景下,PC厂商正在把CXMT的DRAM纳入采购选项。

Insight by AI PC厂商在高带宽内存持续被AI数据中心吸纳、传统DRAM供应紧缺的背景下,把国产DRAM纳入采购,既是短期保供的无奈之举,也可能在中端机型中固化出一条非美系内存的长期供应线。

美政府拟禁止进口中国数据中心设备

Insight by AI 若该禁令落地，将进一步加速美国数据中心供应链与中国厂商的脱钩，并可能推动服务器、交换机等关键设备的本土化替代进程。

LongHorizon-Harness 用三段式管理重构长时程 Agent

论文指出，长时程任务普遍要求 LLM Agent 在多步骤间持续推理、调用工具并修订，但现有 harness 把任务执行、任务状态与完成判定都塞进不断增长的上下文，导致状态难以追踪、错误的自评估会向后传播。作者将长时程执行改写为任务状态管理问题，提出 LongHorizon-Harness：把任务状态显式放在执行之外，仅以环境中独立核实的事实更新。其 Manage-Execute-Audit 循环由 manager 维护任务状态并决定下一子任务、由 fresh-context 的 executor 执行、由只读 auditor 核对环境状态后再进入下一轮，并附带轻量 AgentAdapter 以便在不改原有 agent 循环的前提下替换模型与 harness 后端。论文报告，LongHorizon-Harness 将 Qwen 3.7-Plus 在 WeaveBench 上由 51.8% 提升到 80.7%，在 Terminal-Bench 2.1 上由 69.7% 提升到 77.2%，在 OSWorld 2.0 上由 2.8% 提升到 8.3%；并把 Claude Opus 4.7 在 OSWorld 2.0 子集上由 20.0% 提升到 34.3%。

Insight by AI 把状态从执行上下文中外置并强制走“独立核实”链路，是长时程 Agent 工程化最直接的杠杆；MEA 分离配合 AgentAdapter 也意味着 harness 与模型可独立迭代。

AgentMemBench 在统一条件下横评五种长期记忆策略

论文指出，对话 AI Agent 有限的上下文窗口难以支撑跨上千轮的一致回忆，长期记忆仍是关键瓶颈。作者提出统一且可复现的基准 AgentMemBench，在相同条件下评测五种长期记忆管理策略：in-context windowing（ICW）、external key-value store（EKV）、graph-based episodic memory（GEM）、compression-based summarisation（CBS）、web-augmented memory（WAM）。评测覆盖 LoCoMo、MultiDoc2Dial、MSC 三个公开数据集共 491 个标注问题，使用 Recall@k、MRR、nDCG@k、Answer F1、LLM-judge Faithfulness、Memory Footprint 与 Latency，并以 Qwen2.5-7B-Instruct（4-bit）配合 greedy decoding 保证确定性。报告结果显示，EKV 在所有质量维度上领先，宏观 Recall@5 达 0.792、MRR 0.677、F1 0.156、Faithfulness 0.354；在 LoCoMo 的远距离回忆上，ICW、WAM、GEM、CBS 的 Recall@5 均 ≤ 0.005，仅 EKV 达到 0.573，且 CBS 以 0.556 排在检索次席；EKV 的优势伴随足迹开销，约 5,100 token，而 ICW/WAM 约 300 token。论文同时把 MemGPT/Letta 与 HippoRAG 接入同一 harness 进行对比，并开源全部代码、环境与结果产物。

Insight by AI 在长跨度会话里，仅有“密集检索”类存储（EKV）能维持可用回忆，传统窗口、摘要与实体图均会在长程坍缩；评测同时把 footprint 与延迟纳入指标，明确把记忆系统拉到“精度–效率权衡”框架。
arXiv cs.CL

DLLM-TTS 用块离散扩散重做语音合成

论文指出，自回归 codec 语言模型 TTS 语音可懂度高但解码串行、模型与数据规模偏大，非自回归方法换速度却损语言精度。作者提出 DLLM-TTS，把 TTS 形式化为 X-Codec2 神经音频 codec 令牌上的条件块离散扩散：序列先分块，块内做掩码扩散，块间串行处理，以同时学习局部声学连贯与全局文本–语音对齐。推理时块内并行预测，实测实时因子 0.15；0.6B 参数模型在 20K 小时训练数据下，于 Seed-TTS-eval 上达到与对照方案可比的表现。

Insight by AI 把“非自回归”粒度从整句细化到块内并行、块间串行，是 TTS 兼顾速度与可懂度的折中点；0.6B 配 20K 小时就能追平既有方案，暗示 codec 令牌表征显著降低语音合成对数据与参数的依赖。
arXiv cs.CL
