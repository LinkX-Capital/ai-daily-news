模型前沿

蚂蚁集团发布 Ling-3.0-flash-VL 开源多模态模型

蚂蚁集团旗下 AntLingAGI 推出开源权重推理模型 Ling-3.0-flash-VL，在 Ling-3.0-flash 基础上新增图像与视频理解能力。该模型采用混合专家架构，总参数量 124B，激活参数量 5.5B。Artificial Analysis 智能指数给出 25 分，并指出该模型落在 Intelligence vs. Active Parameter Pareto Frontier 上。

Insight by AI 在 flash 档位上以 5.5B 激活参数跻身 Pareto 前沿，说明 MoE 稀疏激活配合视觉扩展正在压缩小激活参数模型的智能差距，为开源侧多模态推理模型提供了一个明确性价比锚点。
@artificialanlys

商汤发布 8B 统一多模态模型 SenseNova-U1.5，主打端到端理解与生成

SenseNova-U1.5 采用 8B MoT 架构的原生统一多模态模型，在不含独立编码器与 VAE 的设计中同时支持视觉理解、推理与生成。其视觉接口通过空间一致的 patch 重建得到强化，训练数据经过精心筛选的任务构造、结构化提示增强与最高 4K 的原生分辨率。后训练阶段分别针对视觉美学、双语文本渲染、信息图生成与图像编辑优化专家模型，再通过多专家在策略蒸馏合并能力。在多项评测中，该模型在图像保真度、文本渲染、复杂组合、多参考编辑与交错生成上取得明显提升，并在指令跟随、主体身份、几何与未改动区域保持方面有所改善。论文同时宣布将开源监督微调、强化学习与在策略蒸馏的训练代码。

Insight by AI 把编码器与 VAE 一并去掉、把理解与生成放进同一原生多模态栈，正在成为多模态路线的一种激进选项；其收益取决于能否用 patch 重建与高质量生成数据替代传统视觉 tokenizer 的先验，而开源训练代码则意味着这类架构的可复现性将快速被社区检验。

Oracle 季度营收增长 30%，靠客户预付款覆盖大部分资本开支

Oracle 在截至 8 月 31 日的季度录得 30% 的营收同比增长，略高于 6 月给出的指引，盘后股价上涨 4.4%。季度内 Oracle 资本开支达 285 亿美元，但其中仅 50 亿美元来自公司自有资金，其余由客户预付款覆盖。该季度预付款规模达 114 亿美元，约为经营性现金净流入的两倍。

Insight by AI 客户预付款规模超过经营性现金流，意味着 AI 算力需求方开始主动为产能融资；这种"先付款再排队"的结构让超大规模云厂商可以用更低自有杠杆扩张，但同时也把建设节奏的风险反向转嫁给了需求方。

SemiAnalysis：GB300 NVL72 在 Agent 推理上每美元性能可达 Hopper 的 13 倍

SemiAnalysis 在 X 上表示，GB300 NVL72 通过铜背板把可扩展域从 Hopper 时代的 8 卡扩展到 72 卡，因此在 Agent 类推理负载上每美元性能可达到 Hopper 的约 13 倍。文中强调，这一收益来源于极致的协同设计，并举例称 vLLM 的宽专家并行（wide expert parallelism）可以让每块 GPU 只持有部分专家参数。

Insight by AI 把 scale-up 域从 8 卡拉到 72 卡，本质上是把 MoE 推理的并行粒度嵌进整机柜拓扑；这一硬件假设会让推理栈、专家切分策略与调度器进一步向 NVIDIA 整机柜耦合，独立 GPU 厂商在 MoE 推理上追赶的难度被再次拉高。

研究关注

论文提出 World Model RL：用世界模型替代环境执行缓解自动科研智能体的训练瓶颈

论文指出，自动科研智能体的强化学习后训练中，智能体生成与环境执行两部分具有不同的可扩展性，前者可经批处理共享算力，后者各自独占沙箱与机器时间，因而随轨迹增长成为主要瓶颈。为此，作者提出 World Model RL（WMRL），用世界模型取代环境执行来移除这一瓶颈，并配套 Online Debiasing 与 Inverse-Variance Denoising 两种机制，分别用于抵消奖励偏差与抑制噪声。作者在论文中给出收敛性证明，并在多种智能体规模的任务上报告 3–4 倍的训练加速。经后训练得到的 4B 与 9B 智能体在留出基准上超过了 48B 与 120B 的开源权重智能体。该方法在具身 VLA 策略的后训练中也展现出可迁移性。

Insight by AI 当 RL 进入智能体长轨迹训练时，环境的真实执行开销往往压过生成侧，单纯堆算力并不能线性换性能；用世界模型做替代执行并显式建模奖励偏差与方差，是把 AutoResearch 后训练拉向更大规模的一条务实路径，也使同一框架有望延伸到具身策略后训练。

论文提出 SyncWorld：以视觉标定让世界模型成为零样本机器人仿真器

论文指出，世界模型用作策略在环的想象环境时，低层机器人动作在像素空间中并非通用语言，视觉环境、相机视角、机器人位姿或本体的改变会让同一数值动作产生不同视觉表现，从而带来冲突监督与部署时泛化脆弱的问题。SyncWorld 通过一段视觉标定片段，即同时给出可控自由度的配对帧与动作，在上下文中刻画具体配置下的动作–视觉映射，使世界模型在未见环境下也能直接作为零样本仿真器使用。训练时引入视觉标定上下文后，模型学会通过视觉证据解读动作，并在缺少显式标定时利用交互历史。其能力使测试时策略改进无需额外训练即可完成。

Insight by AI 世界模型在机器人中的瓶颈往往不是画面生成质量，而是动作到像素的细粒度对应；把少量现场视觉标定作为上下文而非额外训练数据，是降低部署耦合、提升仿真可迁移性的一个轻量思路，对策略在环想象环境尤为关键。

Artificial Analysis 首次将多模型编码 Agent Devin Fusion 纳入编码 Agent 指数

Artificial Analysis 在 Devin Fusion 当日发布版本上完成独立基准测试，这是其 Coding Agent Index 首次纳入多模型编码 Agent 产品。测试结果显示，Devin Fusion 由 Cognition 配置的 frontier 主导模型配合 cost-efficient sidekick，在性能上有效保留 Claude Fable 5.1 与 GPT-6 Astra 表现并降低成本。

Insight by AI Devin Fusion 把 frontier 主模型与轻量副模型组合成同一 Agent，是把推理成本曲线压低的工程化路径；进入第三方编码 Agent 指数意味着多模型协作 Agent 开始被纳入与单体模型可比较的评测框架。
@artificialanlys

Cognition 在 Devin CLI 中推出 Fusion，可在规划与执行阶段分别选用不同模型

Cognition 宣布在 Devin CLI 中引入 Fusion，面向其 Fable 与 Astra 模型。据该帖文描述，Fusion 被称为面向这两个模型的高效前沿 harness，在编码基准上比此前便宜 39%。用户可以为规划阶段选择偏好的模型，为执行阶段选择更具成本效益的模型。

Insight by AI 把规划与执行解耦并允许在两端各选不同模型，是在模型能力快速分化的当下平衡质量与成本的一种现实选择；Fusion 类机制把这种选择权直接交到用户手里，也意味着模型 API 不再只按单一端到端能力定价。
